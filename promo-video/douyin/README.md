# 易象图谱抖音发布素材

这套素材面向抖音通用发布场景，全部采用 16:9 横屏构图，不代表开发手机版产品。

## 交付内容

- `yijing-atlas-douyin-trailer-1080p.mp4`：75 秒带配乐、拟音成片。
- `yijing-atlas-douyin-trailer-1080p-nobgm.mp4`：保留拟音的无配乐版，便于后续加入专业旁白与重新混音。
- `yijing-atlas-douyin-cover-1920x1080.png`：横屏封面。
- `narration.zh-CN.txt`：专业中文旁白录音稿。
- `subtitles.zh-CN.srt`：逐段对时字幕。
- `publish-copy.md`：标题、正文、标签和置顶评论。
- `shot-list.md`：逐秒分镜和剪辑意图。

## 发布建议

上传时使用带配乐版；完成男女声专业录音后，将人声混入无配乐版并把背景音乐压低约 4–6dB。封面标题应保持完整，不要再叠平台模板文字。推荐发布时段为目标受众活跃期，首发后用置顶评论承接体验与开源入口。

当前成片没有内嵌旁白字幕。发布时必须导入 `subtitles.zh-CN.srt`，或在平台字幕工具中按同一时间码创建字幕；否则画面只保留镜头内的功能标题。

配乐与音效授权沿用 [`AUDIO-ATTRIBUTION.md`](../AUDIO-ATTRIBUTION.md)。发布前应保留授权文件快照。
