## 发布正文

很多人知道《易经》值得学，却常常卡在第一步：卦象难认、关系难懂，看完还记不住。

所以我做了「易象图谱」：64 卦、384 爻、552 道动态题目，`web/js/` 下 43 个模块累计 7967 行 JavaScript 代码、60 次提交，默认发布质量门的 34 组测试全部通过。

它不只呈现内容，还把星图探索、卦象演变、5 阶 21 课、小试抽查、错题回炉和间隔复习连成完整学习闭环。

目前正在做最后整理。想体验在线版、查看 GitHub 开源项目或下载 Windows 一键版，可以先关注，发布时第一时间通知。
