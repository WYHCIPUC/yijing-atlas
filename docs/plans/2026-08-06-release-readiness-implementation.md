# 易象图谱发布完善实施计划

状态：已完成（2026-08-06）

## 目标与边界

在不引入运行时依赖、不改变核心历法算法的前提下，完成稳定性、首屏性能、搜索与无障碍、学习闭环和发布治理。代码达到可发布状态，但本轮不创建或推送 GitHub 远程仓库。新增或修改的核心逻辑覆盖率不低于 90%，最终以 `npm run validate` 为基础发布门禁。

## T1 · 本地数据与学习指标（default）

- 范围：`web/js/storage.js`、测验/复习/学习进度模块、用户数据导入导出及对应测试。
- 内容：统一安全读写与结构校验；记录学习活跃日期、连续学习天数；支持错题定向出题；兼容现有 localStorage 数据。
- 依赖：无。
- 验证：新增单元测试；`npm run test:coverage`。

## T2 · 产品学习闭环（ui）

- 范围：学习、测验、复习、占筮模式及相关样式。
- 内容：进度仪表板、错题回练入口、连续学习反馈、最多 50 条占筮历史及清理操作；存储失败给出可感知提示。
- 依赖：T1。
- 验证：模式渲染烟雾测试、键盘交互检查。

## T3 · 首屏加载与离线缓存（default）

- 范围：`data-loader.js`、`main.js`、`sw.js`、`index.html`、PWA 测试。
- 内容：启动仅加载核心数据，模式数据按需加载；模式模块动态导入；移除外部字体依赖；去除重复查询版本号，缩减首装预缓存并保持运行时离线缓存。
- 依赖：无。
- 验证：数据加载测试、PWA 资产测试、首屏网络请求断言。

## T4 · 搜索、深链接与无障碍（ui）

- 范围：入口页、详情渲染、搜索控制器、主样式及测试。
- 内容：搜索结果列表、空状态和方向键导航；`?hex=` 可分享详情及前进/后退；详情对话框焦点管理；页签方向键导航；今日卦每会话仅自动展示一次。
- 依赖：T3。
- 验证：纯逻辑单元测试、DOM 烟雾测试、浏览器烟雾测试。

## T5 · 工程与发布治理（quick-fix）

- 范围：质量脚本、GitHub Actions、README、许可证、第三方声明、发布文档。
- 内容：MIT 代码许可；d3-force 第三方声明；零依赖静态规范检查；可选真实浏览器烟雾测试并接入 CI；同步计划状态与发布检查清单。
- 依赖：T1-T4。
- 验证：`npm run check`、`npm run test:e2e`、`npm run validate`、最终 diff 检查。
