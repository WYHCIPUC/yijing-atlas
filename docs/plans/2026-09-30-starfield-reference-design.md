# 星空参考与实现 · 2026-09-30

用户要求星空的感觉参考两段小红书视频。本轮调整探索星图的背景、星点和轨道，沿用原生静态站点、Canvas 与现有 Three.js，未新增依赖。

## 实现

- `web/js/star-atmosphere.js`：确定性多尺度噪声生成银河云带、亮尘和暗尘缝；冷灰蓝边缘、微暖核心，留足暗部。纹理最多 960×540、约 2 MB 原始像素，不逐帧生成。
- `web/js/star-map.js`：预渲染分层细星、银河纹理与尘点；镜头轻微视差；不同卦星使用独立低幅明灭，收小普通星核和光晕。八卦锚点、六十四卦位置、六爻卫星、关系规则及点击范围沿用原实现。
- `web/js/celestial-stage.js`：探索模式外轨转为银白、减细环线并放慢远星移动；减弱 WebGL 雾光，避免覆盖 Canvas 银河。
- 页面资源和 Service Worker 统一到 v50，将新增背景模块以及缺失的两个首屏依赖加入预缓存；测试直接从 HTML 读取入口资源，避免硬编码旧版本。
- 修正视差误读镜头字段导致背景坐标为 NaN 的问题；回归测试先复现失败，再确认正常与减少动态效果两种状态均正确。

- 新增测试覆盖纹理可重复性、尺寸和内存上限、明暗分布、非法尺寸、背景有效绘制坐标与减少动态效果的静止行为。
- 浏览器实际检查银河显示、搜索乾卦、打开/关闭详情、放大到 125%、切换先天八卦、返回易象银河及切换学习工作台。
- 恢复默认视口后已保存 [实际页面截图](../screenshots/2026-09-30-starfield.jpg)，最终控制台未发现错误或警告。

## 剩余边界

- 聚焦乾卦且侧栏打开时，部分关键词可见重叠；作为独立布局问题保留，未用降低背景亮度掩盖。
- 减少动态效果通过代码与回归测试验证，尚未在操作系统设置中切换实测；未进行低端 GPU 帧耗测量、跨浏览器或移动真机验收。
- 入口缓存资源已统一到 v50 并通过静态测试；`main.js` 的懒加载模块仍有 `?v=48`，首次安装后断网重开的完整流程仍待验证。
- 全项目审计中的其他缺陷仍以 [优化清单](2026-09-30-project-audit.md) 为准，本轮视觉改进不改变全项目的 Block 判定。
