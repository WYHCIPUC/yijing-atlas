## 壹 · 梅花易数

### 一、历史渊源与文化背景

#### 1.1 得名由来——观梅占

梅花易数，又名"周易梅花数""梅花心易"，相传为**北宋著名易学家邵雍（字康节，1011-1077）**所创。其得名来自一个著名的占例——**观梅占**：

> 辰年十二月十七日申时，邵康节先生偶在梅花园中观梅赏花，见**两只麻雀争枝坠地**。先生认为"不动不占，不因事不占"——雀争坠地属异常之兆，遂据时起卦。推算后断言：**次日晚有邻家女子来折花，被园丁惊赶而跌伤股部（大腿）**。后果然应验。

此后世人称此法为"观梅数"，渐传为"梅花易数"。这个典故揭示了梅花易数的第一原则：**万物皆可为兆，心有所动即可起卦**。

#### 1.2 经典占例

梅花易数传世有多个经典案例，展现了"随时随地、万物皆可起卦"的精髓：

| 典故 | 起卦方式 | 要旨 |
|---|---|---|
| **观梅占** | 观物（雀争坠地）+ 时间 | 梅花易数得名之源 |
| **邻夜扣门借物占** | 闻声（叩门一声+五声） | 断出所借为金斧之物，"闻声占"典范 |
| **西林寺匾额占** | 见字（"西林寺"匾额笔画） | 断寺中有阴人之祸，"字占"典范 |
| **牡丹占** | 观物（赏牡丹时） | 占牡丹能否长存 |
| **老人有忧色占** | 观人面色 | 见老人面有忧色，占其吉凶 |
| **少年有喜色占** | 观人面色 | 见少年面有喜色，占其将有何喜 |

这些典故共同诠释了梅花易数的核心理念——**"不动不占，不因事不占，不惊不占"**。天地万物、声音字画、人的神色举止，无一不可作为起卦的契机。

#### 1.3 与金钱卦、大衍筮法的区别

| 维度 | 大衍筮法 | 金钱卦 | 梅花易数 |
|---|---|---|---|
| **起源** | 周代（最古老） | 汉代京房改良 | 北宋邵雍 |
| **工具** | 50 蓍草 | 3 枚铜钱 | 无需工具（时间/数字/万物） |
| **耗时** | 18 变约半小时 | 掷 6 次数分钟 | 瞬间起卦 |
| **断卦核心** | 变爻取辞 | 变爻取辞 | **体用生克**（本卦为体、变卦为用） |
| **特点** | 古朴庄重 | 简便经典 | 灵活直觉，重象数理 |

**关键区别**：金钱卦和大衍主要靠"变爻取辞"（看哪根爻变、查对应爻辞），而梅花易数独创了**"体用分析"**——不看爻辞，看本卦与变卦的五行生克关系来断吉凶。这是梅花易数最独特、最有算法化的部分，非常适合程序实现。

### 二、算法原理

#### 2.1 起卦口诀

> **卦以八除，爻以六除。**
> 上卦 = 上数 ÷ 8 的余数（整除取 8）
> 下卦 = 下数 ÷ 8 的余数（整除取 8）
> 动爻 = (上数 + 下数) ÷ 6 的余数（整除取 6）

#### 2.2 先天八卦序映射（起卦专用）

注意：起卦用**先天八卦序**（伏羲八卦），不是后天八卦序（文王八卦）。

```
余数  1      2      3      4      5      6      7      8
卦名  乾     兑     离     震     巽     坎     艮     坤
二进  111    110    101    100    011    010    001    000
自然  天     泽     火     雷     风     水     山     地
```

#### 2.3 两种起卦法

**① 数字起卦**（最灵活）：
- 输入任意两个数字（如心念所至的数、车牌号、电话号拆分）
- 上数 ÷ 8 余数 → 上卦；下数 ÷ 8 余数 → 下卦
- (上数 + 下数) ÷ 6 余数 → 动爻

**② 时间起卦**（最传统）：
以农历年月日时为依据：
- 上数 = 年支数 + 月数 + 日数
- 下数 = 年支数 + 月数 + 日数 + 时辰数
- 年支数：子1 丑2 寅3 卯4 辰5 巳6 午7 未8 申9 酉10 戌11 亥12
- 时辰数同理（子时=1…亥时=12）

#### 2.4 体用分析（断卦核心）

这是梅花易数的灵魂。得到本卦（6 爻）和动爻位置后：

- **体卦** = 本卦中**不含动爻**的那个三爻卦（上卦或下卦）
- **用卦** = 本卦中**含动爻**的那个三爻卦
- 体代表**自己/主体**，用代表**所测之事/客体**

**八卦五行属性**：
```
乾兑 = 金    震巽 = 木    坎 = 水    离 = 火    坤艮 = 土
```

**体用五行生克五局**（吉凶判定）：

| 关系 | 含义 | 吉凶 | 断语 |
|---|---|---|---|
| **用生体** | 所测之事助益自己 | 大吉 | 事可成，多有助益，顺遂如意 |
| **体生用** | 自己耗费精力去就事 | 小凶 | 事难成，劳神费力，泄气耗损 |
| **体克用** | 自己能控制局面 | 小吉 | 费力可成，经过努力可达 |
| **用克体** | 所测之事阻碍自己 | 大凶 | 不宜妄动，有阻难，事多不成 |
| **体用比和** | 双方五行相同 | 中吉 | 顺其自然，平稳无碍 |

**五行相生**：金生水、水生木、木生火、火生土、土生金
**五行相克**：金克木、木克土、土克水、水克火、火克金

#### 2.5 进阶：旺衰分析（可选）

结合起卦时的时令判断体卦旺衰，使断语更精确：
- **春**：木旺、火相、水休、金囚、土死
- **夏**：火旺、土相、木休、水囚、金死
- **秋**：金旺、水相、土休、火囚、木死
- **冬**：水旺、木相、金休、土囚、火死

体卦临旺相则力量强，临休囚死则力量弱。

```javascript
// 先天八卦序：余数1-8 → 二进制码
const XIANTIAN = ['', '111', '110', '101', '100', '011', '010', '001', '000'];

// 数字起卦
export function castByNumber(upperNum, lowerNum) {
  const upIdx = ((upperNum - 1) % 8) + 1;  // 1-8
  const lowIdx = ((lowerNum - 1) % 8) + 1;
  const upperTrigram = XIANTIAN[upIdx];
  const lowerTrigram = XIANTIAN[lowIdx];
  const primaryCode = lowerTrigram + upperTrigram; // 下卦+上卦
  const yaoIdx = ((upperNum + lowerNum - 1) % 6) + 1; // 动爻1-6
  // 变卦：翻转动爻
  const changedArr = primaryCode.split('');
  changedArr[yaoIdx - 1] = changedArr[yaoIdx - 1] === '1' ? '0' : '1';
  const changedCode = changedArr.join('');
  return { upperTrigram, lowerTrigram, primaryCode, changingPos: yaoIdx, changedCode, method: 'number', source: `上数${upperNum} 下数${lowerNum}` };
}

// 时间起卦（农历）
export function castByTime(date) { /* 年支+月+日 为上数，+时辰为下数 */ }
```

## 贰 · 黄历（通胜）

### 一、历史渊源与文化背景

#### 1.1 从"日书"到"皇历"再到"通胜"

黄历的历史可追溯至**战国至秦汉时期的"日书"**——写在竹简上的择吉指南，出土的睡虎地秦简《日书》已有完整的宜忌体系。

古时历书由**朝廷掌管天文历法的官署**（如汉代太史令、唐代太史局、明清钦天监）编算，以皇帝名义颁行，故称**"皇历"**。谐音"黄历"。在粤语地区，因"书"与"输"同音忌讳，将"通书"改称**"通胜"**，取通达胜利之意。

#### 1.2 协纪辨方书——集大成之作

**《钦定协纪辨方书》**，清**乾隆四年（1739年）**敕撰，由允禄、梅瑴成等编篡，是中国古代择日术的集大成之作，收入《四库全书》。

乾隆御制序言强调两个核心理念：
- **"敬天之纪"** —— 敬畏天体运行的规律（天文）
- **"敬地之方"** —— 遵循地理方位的宜忌（择吉）

全书"崇正辟邪"，旨在破除迷信和拘忌，将择日术系统化、理论化。本项目黄历模块的建除、宜忌规则即以此书为口径。

#### 1.3 黄历各要素典故

**建除十二神（值日）**
> 历家以**建、除、满、平、定、执、破、危、成、收、开、闭**凡十二日，周而复始，观所值以定吉凶。每月交节则叠两值日，其法从月建上起建，与**斗杓所指**相应。——《协纪辨方书》

十二值位各有宜忌取向：
- **建**：万物生育之日，宜谒贵、上任；忌动土、开仓
- **除**：扫除恶煞之日，宜治病、沐浴；忌嫁娶
- **满**：丰收圆满之日，宜祭祀、补垣；忌安葬
- **平**：平平无奇之日，诸事平常
- **定**：安静守持之日，宜祭祀、立约；忌诉讼、出行
- **执**：固执不变之日，宜捕猎；忌开市
- **破**：冲破消耗之日，诸事不宜
- **危**：危险之日，忌登高、行船
- **成**：成就之日，宜结婚、开市、入学
- **收**：收敛之日，宜收割、买物；忌出行
- **开**：开通之日，宜开市、迁居；忌安葬
- **闭**：闭塞之日，宜筑堤；忌开市

**二十八宿（值宿）**
中国古代将天空赤道带分为**二十八宿**（四方各七宿），每日一宿值日：
- **东方苍龙**：角亢氐房心尾箕
- **北方玄武**：斗牛女虚危室壁
- **西方白虎**：奎娄胃昴毕觜参
- **南方朱雀**：井鬼柳星张翼轸

每宿有吉凶属性，如角宿吉（宜造作、婚嫁）、亢宿凶（忌动土）。源于古代星占学，后融入黄历。

**彭祖百忌**
相传源自**彭祖**（传说寿八百岁的仙人）。每日天干地支各有一条忌讳，朗朗上口：
- 天干忌：**甲不开仓**财物耗散、**乙不栽植**千株不长、**丙不修灶**必见灾殃……**癸不词讼**理弱敌强
- 地支忌：**子不问卜**自惹祸殃、**丑不冠带**主不还乡……**亥不嫁娶**不利新郎

这些口诀至今仍是民间黄历的标配，虽有经验色彩，但承载了千百年的民俗智慧。

#### 1.4 天文算法传承

黄历的核心是**农历算法**，而农历的核心是**定朔定气**：
- **定朔**：以日月黄经相同（合朔）的时刻定每月初一
- **定气**：以太阳黄经每 15° 为一个节气

本项目采用**寿星天文历**（许剑伟）的成熟算法：
- 太阳黄经：VSOP87 截断级数
- 月亮黄经：ELP2000 简化
- 含章动、光行差修正
- 精度目标：节气误差 < 1 分钟，农历与紫金山天文台历书一致
