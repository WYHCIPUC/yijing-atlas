## 一、模块概述

### 梅花易数
邵雍（邵康节）所传的简便起卦法，以**时间、数字、方位**等随机信息起卦，无需蓍草铜钱。核心是"卦以八除、爻以六除"——上卦取上数÷8 余数，下卦取下数÷8 余数，动爻取总数÷6 余数。特点是**起卦灵活、断卦重体用**（本卦为体、变卦为用，看体用生克）。

### 黄历（通胜）
内置完整农历算法，以当天日期切入做全面解读（农历、干支、节气、建除、二十八宿、彭祖百忌、宜忌）。与易经同源（皆明天人合一、择吉避凶之理）。

## 二、梅花易数开发计划

### 数据与算法

#### Task M1：梅花易数起卦引擎
**文件**：新增 `web/js/meihua-engine.js`

- [ ] **数字起卦**：输入两个数字（或时间生成的上下数）
  - 上卦 = 上数 ÷ 8 的余数（0 时取 8），对应先天八卦序（乾1兑2离3震4巽5坎6艮7坤8）
  - 下卦 = 下数 ÷ 8 的余数，同理
  - 动爻 = (上数 + 下数) ÷ 6 的余数（0 时取 6），自下而上数
- [ ] **时间起卦**：以当前时间（年月日时辰）生成上下数
  - 上数 = 年支数 + 月数 + 日数
  - 下数 = 年支数 + 月数 + 日数 + 时辰数
  - 年支数：子1丑2…亥12；月数：农历月；日数：农历日；时辰数：子1…亥12
- [ ] **返回结构**：
  ```js
  {
    upperTrigram,   // 上卦二进制 "111"-"000"
    lowerTrigram,   // 下卦二进制
    primaryCode,    // 本卦 6 位串
    changingPos,    // 动爻位置 1-6
    changedCode,    // 变卦
    method,         // 'number' | 'time'
    source,         // 输入数据描述
  }
  ```

**验证**：
```bash
cd web && node --input-type=module -e "
import { castByNumber, castByTime } from './js/meihua-engine.js';
console.log('数字起卦(3,7):', castByNumber(3, 7));
console.log('时间起卦:', castByTime(new Date()));
"
```

#### Task M2：梅花易数断卦（体用分析）
**文件**：`web/js/meihua-engine.js`（追加）

梅花易数的核心是**体用生克**：
- [ ] 本卦中**无动爻的卦为体卦**（代表自己），**有动爻的卦为用卦**（代表所测之事）
- [ ] 八卦五行属性：乾兑=金、震巽=木、坎=水、离=火、坤艮=土
- [ ] 体用五行生克关系：用生体=吉、体生用=泄、体克用=得、用克体=凶、体用比和=顺
- [ ] 返回断语：
  ```js

    useTrigram,     // 用卦
    bodyWuxing, useWuxing,
    relation,       // 'sheng'(用生体) | 'xie'(体生用) | 'ke'(体克用) | 'beike'(用克体) | 'bihe'(比和)
    verdict,        // 吉凶判定文字

  ```

## 五、技术要点

### 梅花易数先天八卦序（起卦映射）
```
余数 1=乾(111) 2=兑(110) 3=离(101) 4=震(100)
余数 5=巽(011) 6=坎(010) 7=艮(001) 8=坤(000)
```
注意：先天八卦序 ≠ 后天八卦序。起卦用先天序，方位解读可参考后天序。

### 八卦五行（体用分析用）
```
乾兑=金  震巽=木  坎=水  离=火  坤艮=土
```

### 体用生克判定
- 用生体 → 吉（事可成，有助益）
- 体生用 → 泄（耗费精力，事难成）
- 体克用 → 得（费力可成）
- 用克体 → 凶（不宜，有阻）
- 体用比和 → 顺（顺其自然）

### 黄历精度验证基准（北京时间 UTC+8）
来自紫金山天文台《中国天文年历》：
- 2026 夏至 6/21 16:24
- 2026 小暑 7/7 09:57
- 2026 大暑 7/23 03:13
- 2026 立秋 8/7 19:42
- 2025 冬至 12/21 23:02
