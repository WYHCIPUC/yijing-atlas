# 卦象演变实验室 MVP

## 目标

在卦象详情中加入可操作的演变实验室。用户可以直接切换六爻，实时查看结果卦、变化说明和历史，并通过错卦、综卦、互卦预设理解常见关系。

## 范围

1. `default`：新增纯状态模型，处理逐爻变化、预设、撤销、重做、重置和差异计算。
2. `ui`：实现响应式实验室浮层、键盘焦点管理、快捷键和详情入口。
3. `default`：补充单元测试、浏览器烟雾测试与离线缓存条目。

本阶段不包含星图语义缩放、个人仪表板或服务端同步。

## 验收

- 六位卦码始终按自下而上表示，点击第 N 爻只修改索引 `N - 1`。
- 撤销、重做、重置和分支历史行为正确。
- 错、综、互预设得到现有领域函数相同的结果。
- 桌面和移动端可完整操作；Esc、Tab、Ctrl/Cmd+Z 可用。
- `npm run validate` 与 `npm run test:e2e` 通过，既有覆盖率门禁保持不变。
