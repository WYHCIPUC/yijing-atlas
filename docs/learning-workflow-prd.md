# 学习闭环与书院考评 PRD

## 目标

将现有互相独立的学习路径、测验、错题与复习能力整合为可追踪的课程闭环。用户可以自由浏览全部内容，不因成绩被锁课；系统通过日课、小试、抽查、复讲与阶段考评呈现掌握度、薄弱点和下一步建议。

## 教学原则

- **时习与温故**：完成学习后安排小试和跨课抽查，呼应《论语》的“学而时习之”“温故而知新”。
- **学问思辨行**：课程操作依次覆盖阅读、辨析、复讲和应用，参考《礼记·中庸》的“博学、审问、慎思、明辨、笃行”。
- **阶段考校**：以小节检验和阶段考评替代一次性总考试，参考《礼记·学记》“比年入学，中年考校”及“小成”“大成”的递进思想。
- **现代化边界**：不设置惩罚、排名或强制解锁；学阶只表达个人掌握状态。

典籍核验：[《论语·学而》](https://ctext.org/analects/xue-er/zh)、[《礼记·学记》](https://ctext.org/liji/xue-ji/zh)、[《礼记·中庸》](https://ctext.org/liji/zhong-yong/zh)。

## 范围与信息架构

首版覆盖路径、八卦、六十四卦、十翼、象数和黄历知识。学习模块包含：

1. **学程**：总掌握度、书院学阶、连续学习、各阶段/小节状态与推荐日课。
2. **考评**：课后小试（3 题）、随机抽查（5 题）、阶段考评（10 题）和复讲。
3. **资料栏目**：保持八卦、十翼、象数、黄历的自由浏览入口。
4. **数据**：备份学习记录，并配置可选的智能评阅服务地址。

## 评分与状态

每课掌握度由学习 10%、小试 35%、抽查 20%、复讲温习 15%、阶段考评 20% 组成；没有参加的部分计为未检验，不影响内容访问。学阶按总掌握度显示为“初闻、蒙学、习读、明辨、通达”。小节展示最近练习时间、最佳小试和当前掌握度；阶段考评保存历史最佳成绩。

## 智能复讲

前端仅保存服务端点评地址，不保存模型密钥。配置后以固定 JSON 协议提交课程标题、参考要点和用户复讲；服务不可用时自动回退到要点清单自评。评阅结果必须包含分数、概述、优点与改进建议，并标注“智能评阅”或“本地自评”。默认建议同源路径 `/api/learning-review`。

服务端接收：

```json
{"schemaVersion":1,"task":"yijing-learning-recitation","lesson":{"id":"l1-1","title":"阴阳之道"},"rubric":["阴阳互根"],"response":"用户复讲"}
```

成功时返回：

```json
{"score":82,"summary":"能够说明核心关系。","strengths":["概念清楚"],"improvements":["补充典籍依据"]}
```

代理应在服务端读取密钥、限制请求大小与频率，并对模型输出做结构校验；不应记录不必要的复讲原文。

## 验收标准

- 所有课程小节均能生成至少 3 道可自动评分题目。
- 抽查和考评会写入课程级记录，并实时更新掌握度及学阶。
- 旧版已完成记录可迁移为“已浏览”，导入导出包含新版学习数据。
- 智能评阅未配置、超时或返回异常时，复讲仍可通过本地要点自评完成。
- 键盘可完成标签切换、答题、复讲和配置；桌面布局不遮挡主要内容。
