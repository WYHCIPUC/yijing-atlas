# 易象图谱 v1.1.0

本版本补齐项目宣传、发布与本地分发体验，重点展示“看见关系—理解变化—主动回忆—间隔复习—阶段考评”的学习机制。

## 新增内容

- 新增 30 秒与 75 秒 16:9 横屏宣传片，提供带配乐和纯拟音版本。
- 新增抖音横屏封面、小红书项目视觉素材、分镜、字幕与发布文案。
- 新增 Remotion V2 宣传片工程，采用真实页面截图、2.5D 运镜、章节转场和东方幽玄声音设计。
- 更新 README 宣传片入口，统一指向最新版 Release 资源。
- Windows 10/11 x64 单文件版升级至 v1.1.0。

## 下载说明

- `yijing-atlas-v1.1.0-windows-x64.exe`：Windows 本地单文件版，双击后在本机启动服务并打开默认浏览器。
- `SHA256SUMS.txt`：Windows 产物校验值。
- `yijing-atlas-30s.mp4`：30 秒横屏预告，含 BGM 与拟音。
- `yijing-atlas-30s-nobgm.mp4`：30 秒横屏预告，仅保留拟音。
- `yijing-atlas-75s-full.mp4`：75 秒完整介绍，含 BGM 与拟音。
- `yijing-atlas-75s-full-nobgm.mp4`：75 秒完整介绍，仅保留拟音。
- `douyin-cover-1920x1080.png`：16:9 横屏封面。
