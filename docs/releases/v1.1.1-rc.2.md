# 易象图谱 v1.1.1-rc.2

## 发布范围

这是基于现有正式版本 `v1.1.0` 的补丁候选版。rc.1 因 GitHub Release 元数据错误被 superseded；本候选版本的工作流明确使用 `--prerelease`。

## 已验证

- GitHub Actions Quality、Pages 和 Release 工作流均需对当前标签重新执行。
- 生产 URL 返回入口 v50，Service Worker 为 `yijing-atlas-v50`。
- 生产 Lighthouse 三次中位数满足计划门槛：Performance 95、Accessibility 100、Best Practices 100、SEO 100、LCP 2285ms、CLS 0.014。
- Edge 生产浏览器烟测覆盖六个模式、键盘搜索与详情、AX 树、焦点恢复、390/768/1440 视口、黄历时区、梅花/金钱占筮和断网重开。
- 本地 `npm run validate`、Windows 单文件构建和启动测试已在同一代码单元通过；Release 工作流会再次执行这些检查。

## 已知风险

- 尚未取得 Android Chrome、iOS Safari、屏幕阅读器和真实系统 200% 缩放的独立验收证据。
- 六十四卦爻辞、六亲世应及六家注疏仍处于内容校勘门禁，候选版不把未校勘内容宣称为最终出版内容。
- Windows 产物没有商业代码签名证书，首次运行可能出现 SmartScreen 未知发布者提示；发布产物应同时提供 SHA-256。

## 验证环境

- Node.js 22；GitHub Actions Windows runner。
- Microsoft Edge 无头浏览器，生产 URL，1440×1024、768×1024、390×844 视口。
- 真实移动设备、Safari 和屏幕阅读器仍待外部证据补齐。
