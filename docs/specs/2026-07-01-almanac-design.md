## 1. 目标与范围

### 1.1 目标

为易经学习网站新增**黄历（通胜）**功能：内置完整农历算法，以当天日期为切入点进行**全面解读**（农历、干支、节气、建除、二十八宿、彭祖百忌、每日宜忌逐项展开释义），并提供术语学习与复习测验。

黄历与易经同源（皆明天人合一、择吉避凶之理），纳入学习平台使内容体系更完整。

### 1.2 成功标准

- 公历↔农历转换覆盖任意日期（至少 1900-2100），节气精确到分钟
- 每日输出完整黄历：农历日期、年/月/日/时干支、生肖、纳音、节气、建除值位、二十八宿、彭祖百忌、宜忌事项
- 每个黄历术语（建除/宿/百忌/节气/神煞）有结构化深度解读
- 以"今天"为切入，把当日各术语串联成一篇连贯解读
- 黄历术语进入复习卡片与测验，复用已有艾宾浩斯体系
- 全程离线，纯静态，无外部 API

### 1.3 非目标（YAGNI）

- 不做择日反查（"哪天适合嫁娶"这类反向检索）——仅做"某日是什么/宜忌"正向解读
- 不做命理八字排盘（四柱推算复杂且超出黄历范畴）
- 不做实时天象（日出日落、月相图等）——聚焦传统黄历要素
- 不做付费/广告

## 2. 算法层（核心地基）

### 2.1 农历算法选型：寿星万年历

采用 **VSOP87 截断级数 + 定朔定气** 的高精度算法（基于许剑伟"寿星天文历"核心思路），用 JavaScript 实现。

**精度目标**：1900-2100 区间，节气误差 <1 分钟，农历日期完全准确（与紫金山天文台历书一致）。

### 2.2 算法分层（每层职责单一，可独立单测）

```
almanac/
├── astronomy.js      # 天文基础：JD 儒略日、太阳黄经（VSOP87 简化）、月相（定朔）
├── lunar.js          # 农历编排：定朔定月序、中气定闰月、农历日期
├── solar-terms.js    # 二十四节气：基于太阳黄经精确求解
└── ganzhi.js         # 干支体系：年/月/日/时干支、生肖、纳音五行
```

**关键算法**：

| 算法 | 作用 | 验证方式 |
|---|---|---|
| JD（儒略日）转换 | 公历日期 ↔ JD 双向，天文计算统一时间基准 | 与已知 JD 对照 |
| 太阳黄经（VSOP87） | 节气定气、季节判定的基础 | 与天文台节气时刻对照 |
| 定朔求解 | 月亮黄经=太阳黄经时刻 → 农历每月初一 | 与官方历书朔日对照 |
| 定气求解 | 太阳黄经达 15° 整数倍 → 二十四节气精确到分钟 | 与紫金山天文台节气表对照 |
| 农历编排 | 定朔排月序、无中气月为闰月 | 1900-2100 历书全量对照 |
| 干支推算 | 年（立春起）/月（节气起）/日（JD）/时干支 | 与历书干支对照 |

### 2.3 精度保证

- 天文层与农历层每完成一段，立即用 Node 跑**真实数据回归测试**
- 节气用紫金山天文台近年公布的精确时刻逐项核验
- 农历用官方万年历对照月初一与闰月，**不积累错误**

## 3. 择日与解读层

### 3.1 择日引擎（selection.js）

```
建除十二神值日
├── 月建（当月地支）→ 推十二值位：建、除、满、平、定、执、破、危、成、收、开、闭
├── 每个值位有宜忌取向
└── 依据：《协纪辨方书》主流口径

二十八宿值日
├── 按日干支/JD 推算当日值宿（角亢氐房心尾箕…斗牛女虚危室壁…奎娄胃昴毕觜参…井鬼柳星张翼轸）
├── 每宿有吉凶属性与宜忌
└── 与建除、神煞合参

彭祖百忌
├── 天干忌（甲不开仓、乙不栽植…癸不词讼）
├── 地支忌（子不问卜、丑不冠带…亥不嫁娶）
└── 固定规则，直接查表

每日宜忌综合
├── 汇总建除 + 宿 + 百忌 → 当日宜做事项列表 + 忌做事项列表
├── 常见事项约 30 种：祭祀/嫁娶/动土/安葬/开市/移徙/出行/祈福/入宅…
└── 事项 × 值位的宜忌映射表（almanac-yiji.json）
```

### 3.2 解读层（reading.js）——"全面解读"核心

每个黄历术语都有**结构化解读**：

```
{
  name: "定日",
  category: "建除",
  meaning: "建者健也，定者静也……",
  yi: ["祭祀","祈福","立约","安床"],     // 所宜
  ji: ["诉讼","出行","移徙"],             // 所忌
  principle: "依据《协纪辨方书》：……",     // 出处原理
  related: ["岁德","月德"]                  // 关联
}
```

**术语解读库**（almanac-terms.json）覆盖：
- 建除十二神（12 条）
- 二十八宿（28 条）
- 彭祖百忌（10 天干 + 12 地支 = 22 条）
- 二十四节气（24 条，含物候农事）
- 常见神煞（天德、月德、岁破、四废、三合、六合等，若干条）

### 3.3 关键设计：解读库即学习内容

这些解读条目**既是页面展示内容，也是复习卡片与测验题的来源**：
- 复习卡：正面"什么是定日？"，背面取自解读库
- 测验题："建除十二神中，'定日'宜做什么？"选项取自解读库的 yi

查黄历与学黄历天然合一，无需重复造内容。

## 4. 页面与交互

### 4.1 黄历主页（#/almanac）

以**当天日期**为默认切入点：

```
┌─────────────────────────────────┐
│  ◀  2026年7月1日  ▶   [选日期]   │  日期切换（默认今天）
├─────────────────────────────────┤
│  农历：丙午年 五月十七  马年      │
│  干支：丙午年 甲午月 庚寅日      │  年/月/日干支 + 生肖 + 纳音
│  纳音：天河水  沙中金  松柏木    │
│  节气：夏至（第3天）距小暑5天     │  当前节气 + 距下一节气
├─────────────────────────────────┤
│  值宿：角宿  建除：定日          │  可点击查义
│  ✅ 宜：祭祀 祈福 立约 安床 修造  │  每项可点击查义
│  ❌ 忌：开市 动土 安葬 嫁娶 出行  │
│  彭祖百忌：庚不经络 寅不祭祀     │  可点击查义
├─────────────────────────────────┤
│  📖 今日解读                     │  当日各术语串联的连贯讲解
│  ▸ 定日是什么？为什么今天宜…     │
│  ▸ 角宿释义                     │
│  ▸ 庚寅日的含义                  │
└─────────────────────────────────┘
```

**交互**：
- 默认今天，左右箭头/日期选择器切换任意日期
- 每个术语（建除值位、宿、百忌、宜忌事项、节气）可点击 → 展开结构化解读
- "今日解读"区把当天涉及的术语汇总成一篇连贯讲解

### 4.2 黄历知识页（#/almanac-knowledge）

分类浏览所有术语解读（复用学习页折叠展开模式），不依赖具体日期，便于系统学习：
- 建除十二神 / 二十八宿 / 彭祖百忌 / 二十四节气 / 神煞

### 4.3 复习与测验整合

- **复习卡片**：从术语解读库生成，复用 review-engine 的 SM-2 算法
  - 新增题型：建除辨识（给日期猜值位）、术语释义（给术语背含义）
- **测验新增题型**：黄历术语相关（取自解读库）
- 复习/测验页增加"黄历"题源开关

### 4.4 导航整合

- 黄历查询（#/almanac）：独立入口（重要日常功能）
- 黄历知识（#/almanac-knowledge）：归入学习区
- 顶部 Tab 重排，确保 6+ 个入口在小屏可用

## 5. 实施路线

### 5.1 文件结构

```
web/
├── data/
│   ├── almanac-terms.json      # 术语解读库（~100 条）
│   └── almanac-yiji.json       # 宜忌事项 × 值位映射（~30 事项）
├── js/
│   ├── almanac/
│   │   ├── astronomy.js        # 天文基础
│   │   ├── lunar.js            # 农历编排
│   │   ├── solar-terms.js      # 二十四节气
│   │   ├── ganzhi.js           # 干支体系
│   │   ├── selection.js        # 择日引擎
│   │   └── reading.js          # 解读提取
│   ├── almanac-page.js         # 黄历主页
│   └── almanac-knowledge.js    # 黄历知识页
└── styles/main.css             # 追加黄历样式
```

### 5.2 实施顺序（自底向上，按依赖）

1. 天文算法层：`astronomy.js` → `solar-terms.js`（含精度回归测试）
2. 农历编排：`lunar.js` → `ganzhi.js`（含历书对照测试）
3. 术语解读库：`almanac-terms.json` + `almanac-yiji.json`
4. 择日引擎：`selection.js` + `reading.js`（含黄历样本日对照）
5. 页面：`almanac-page.js` + `almanac-knowledge.js`
6. 复习测验整合：扩展 review-engine / quiz-engine
7. 导航整合 + CSS + 验证

### 5.3 验证策略（精度是黄历生命线）

- 节气：紫金山天文台近年节气精确时刻逐一核验（误差 <1 分钟）
- 农历：1900-2100 历书每月初一、闰月全量对照
- 建除/宿：传统黄历样本日对照
- 每段算法完成立即 Node 回归测试，不积累错误

### 5.4 难点与风险

- **最大难点 `astronomy.js`**：VSOP87 截断 + 定朔迭代，移植易出细微错误。用大量已知数据点回归测试化解。
- **建除/宿流派差异**：采用《协纪辨方书》主流口径，解读里注明依据。
- **宜忌映射**为传统经验规则：忠实录入主流黄历通行做法，标注"传统择日通例"。

## 6. 与既有系统的关系

| 既有能力 | 黄历如何复用 |
|---|---|
| 复习引擎 review-engine.js（SM-2） | 黄历术语作为新卡片源接入 |
| 测验引擎 quiz-engine.js | 新增黄历题型 |
| SVG 単象绘制 | 不直接用（黄历以文字/干支为主） |
| data-loader 加载模式 | almanac-terms/yiji.json 同模式加载 |
| 学习页折叠展开 UI | 知识页复用同一交互模式 |
| localStorage 进度存储 | 黄历复习进度同机制 |

黄历模块是**增量扩展**，不改动既有四期功能的逻辑，仅在复习/测验层增加题源。
