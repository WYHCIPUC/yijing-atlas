# 内容来源与使用边界

本项目将内容分为三类，发布前应分别核对：

1. `web/data/hexagrams.json`、`wings.json` 中的《周易》本经与传文属于古典原文整理；标点、分段和录入仍需逐条校对。
2. `theorems.json`、`almanac-terms.json`、`almanac-yiji.json` 以及界面说明为项目整理或改写内容，不应被表述为唯一权威解释。
3. `web/js/almanac/` 的计算参考 Jean Meeus《Astronomical Algorithms》相关公式、Espenak–Meeus ΔT 经验拟合及传统历法规则；测试样例集中在现代年份，不代表对全部计算范围的权威历书认证。

占筮、体用、择日和宜忌功能仅用于传统文化学习与自我反思，不构成医疗、法律、财务、婚姻或其他专业建议。不同版本、学派与地区习俗可能给出不同解释。

仓库根目录的参考 PDF 不属于网站运行资源。其著作权与再分发授权尚未逐项确认，因此不得纳入公开发布包；如历史提交曾包含这些文件，发布时应使用经过审查的干净历史。

新增或修改内容时，请在 Pull Request 中注明来源、改写范围、校对方法和已知争议。引用现代作品时必须记录作者、版本、页码与许可，不得直接复制未获授权的长篇内容。

## 六家注疏工程

演变实验室的扩展注疏范围、数据契约与上线门禁见 [演变实验室产品需求文档](evolution-lab-prd.md)。首版固定覆盖王弼、孔颖达、李鼎祚、程颐、朱熹、来知德六家；数字底本索引记录在 `web/data/commentaries/sources.json`。

中国哲学书电子化计划中的《周易正义》《周易集解》《伊川易传》《周易本义》《周易集注》只作为书目索引、影印定位和录入辅助。部分页面明确标注为 OCR 初稿，因此不得直接批量复制；公开文本必须由项目独立转录，并由两名校对者逐条核对公版影印页。王弼注、韩康伯注和孔颖达疏必须分层署名，李鼎祚《周易集解》所引诸家也须保留原署名。
