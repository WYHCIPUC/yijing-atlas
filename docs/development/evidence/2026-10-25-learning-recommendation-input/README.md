## 方法与数据边界

- 使用现有 Node 24.19.0、独立本地静态服务器和隔离 Chromium profile；未打开或修改用户浏览器配置与学习数据。
- 业务操作采用 CDP `Input` 的鼠标、键盘和模拟触控，记录 DOM 事件的 `isTrusted`；没有调用页面业务函数、`DOM.click()`或直接提交表单。
- DOM 读取和控件 `scrollIntoView`只用于定位、状态及布局观测。续读证据由实际章节链接激活和滚轮/触控滚动产生。
- 推荐顺序使用显式合成 localStorage 夹具，公开题目引用由本地现有题库生成；这些不是用户真实学习证据。保存失败通过合成学习记录键的 `QuotaExceededError` 注入。
- 每次替换夹具前，先通过真实导航退出旧页面完成清理，避免旧页面 `pagehide`覆盖新夹具。
- profile保留用于诊断，不尝试删除。各轮确切路径、源码 SHA-256、环境、命令、快照、输入和截图在各自 `trace.json` 中。

## 执行命令

在仓库根目录运行，先用环境变量选择单个场景；清除该变量后运行全部六个场景。该变量只设置在本次命令进程环境，不改全局配置。

```powershell
$env:YIJING_LEARNING_INPUT_SCOPE = '1440-welcome-resume'
& 'C:\Users\1\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe' docs/development/tools/check-learning-recommendation-input.mjs
```

六场景为：1440与390两个视口，各自运行 `welcome-resume`、`priority-routing`、`save-failure-completion`。390为模拟触控，不是真机。

完整六场景清除`YIJING_LEARNING_INPUT_SCOPE`后执行同一命令。补充窄屏检查使用`$env:YIJING_LEARNING_INPUT_SCOPE = '320-reading-geometry'`；该独立场景不混入默认六场景计数。
