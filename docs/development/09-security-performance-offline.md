## 1. 质量目标与信任边界

主要保护对象是个人笔记、学习证据、备份文件、原始私问、模型密钥和内容来源可信度。
网页代码、公开 JSON 和运行素材属于公开资产，不能靠前端隐藏保护秘密。
当前没有用户账号、服务端会话或数据库；不要套用不存在的登录安全架构。
当前业务默认本地执行，智能评阅是用户主动提交的一条可选外发路径。
未来云端方案需独立立项，本篇不授权新增采集、遥测、账号或同步。

安全、性能和可访问性不能互相替代：自动测试通过不等于真人可读；静态帧稳定不等于真机流畅。
所有验收用隔离测试环境和虚构笔记，不把真实私人资料写进仓库、日志或截图。
任何错误恢复都不得以“清掉所有数据”作为默认第一步。

## 2. CSP、来源和网络行为

依据：[index.html](../../web/index.html)、[learning-review.js](../../web/js/learning-review.js)、[data-loader.js](../../web/js/data-loader.js)。

当前 `<meta http-equiv="Content-Security-Policy">` 约束：

```text
default-src 'self'; script-src 'self';
style-src 'self' 'unsafe-inline'; font-src 'self';
img-src 'self' data:; connect-src 'self';
object-src 'none'; base-uri 'self'; form-action 'self'; worker-src 'self'
```

referrer policy 为 `strict-origin-when-cross-origin`。
脚本、字体、Worker、数据请求使用本地/同源资源；没有必要为 UI 升级放宽到 `*`。
style 目前允许 inline，是现有边界，不应宣称已实施禁止所有内联样式的严格策略。
meta CSP 不等于托管层已经部署所有 HTTP 安全响应头。
不得因未来图片、音频或接口加载失败随意放宽全站 CSP；先确认实际来源和必要性。

### 2.1 可选评阅的外发边界

只在用户点击智能评阅时，发送当前课程 ID/标题、参考要点和本次复讲文本。
请求 `credentials:'omit'`，15秒终止等待；未配置时禁用智能按钮，保留本地自评。
不发送全部笔记、全部localStorage、原始占筮私问或所有历史。
同源路径校验目前是字符串检查，仍需 URL 解析与规范化加固。
反斜杠、协议相对路径、重定向和超长输入要列入接口验收。
`connect-src 'self'` 是独立防线，不能据此省略客户端验证或未来服务端验证。
模型密钥不得出现在URL、输入框、备份、前端源码或浏览器存储。

**建设目标**：保持最小外发与可理解同意提示，精确限制可选端点。
**失败边界**：配置成功不等于连通；请求失败不能丢掉用户已输入的复讲。
**验收**：监听隔离环境网络，默认流程无评阅 POST；主动提交只含协议字段；超时后自评可用。
**任务关联**：[T-API-01](12-ai-execution-tasks.md#t-api-01)。

## 3. XSS、输入和数据可信度

阅读、课程、黄历和评阅结果多数使用 `esc()` 后插入模板，笔记通过 textarea.value 读写。
修改模板时必须区分文本、属性、URL和可信固定SVG，不能只用“有esc”概括所有上下文。
长文本、双引号、单引号、尖括号、实体、换行和长无断词都需要边界用例。
不能把备份中的笔记或未来接口返回直接交给 innerHTML。
错误提示优先 textContent，避免把错误对象当可信HTML。
本地图标路径是固定受控内容，不允许把用户提供的SVG字符串直接安装进DOM。

六位码输入限定0/1长度6；爻位按1—6；三位八卦码与六位卦码要区分。
梅花数字当前检查正安全整数以及和不溢出，日期对象检查有效性。
备份目前有大小/版本/部分结构检查，但不是所有嵌套字段都已严格校验。
原典校勘可信度与XSS防护属于不同事项，不能用文本转义证明文献准确。

**建设目标**：新输入先在纯逻辑入口验证，DOM只消费规范化结果。
**失败边界**：无效导入不得部分覆写；单项字段异常不得让整个工作台白屏。
**验收**：虚构恶意笔记只显示字符，不执行；错误编码给明确反馈；HTML来源保持不可执行。
**任务关联**：[T-BACKUP-02](12-ai-execution-tasks.md#t-backup-02)。

## 4. 本地服务和发布资产边界

Node开发服务器根固定 `web/`，有resolve后的路径边界检查；不提供项目根或父目录。
默认监听127.0.0.1；Python辅助脚本默认0.0.0.0，不能把它们写成同一访问范围。
Windows启动器只GET/HEAD，返回nosniff；Node开发服务不具备完全相同方法/响应头实现。
本地服务本身不是可直接暴露公网的业务后端。
网站根下的文件都可能成为公开资源；“未在菜单链接”不等于不会被下载。
当前Windows构建收集整个web目录，不能把私人资料、密钥或未授权资源先放进去再寄望打包器排除。

`.gitignore` 忽略env、PDF、产物等，不是文件系统泄露扫描器。
质量检查只对当前git跟踪树禁止PDF/证书/私钥扩展名，不扫描所有历史、内容和被忽略文件。
本地复制发布与CI干净checkout也不同，复制目录前仍需看资产清单。
不得声称已经进行了全面依赖漏洞审计、秘密扫描或历史清洗。

**验收**：请求越界路径不可读取根文件；发布目录内无私人样本；资产用途与许可可追踪。
**任务关联**：[T-ASSET-01](12-ai-execution-tasks.md#t-asset-01)、[T-RELEASE-01](12-ai-execution-tasks.md#t-release-01)。

## 5. Service Worker 当前策略

唯一代码依据：[sw.js](../../web/sw.js)。当前缓存名称 `yijing-atlas-v51`。
入口HTML的主CSS、immersive CSS、main模块查询版本与缓存代一致。
模块版本、HTML结构和样式必须同步，避免新版HTML加载旧版协调逻辑。
注册 `updateViaCache:'none'`，注册失败仅警告，不应阻止在线网页。

### 5.1 安装和激活

安装通过 `cache.addAll(PRECACHE)` 预缓存核心清单；任一必需资源失败可使本次安装失败。
当前调用skipWaiting，激活后claim已有页面，存在运行中升级的版本一致性要求。
当前activate枚举本源CacheStorage，删除**所有名称不等于当前缓存代**的缓存。
它尚未只筛 `yijing-atlas-` 前缀；同源多个项目可能受影响。
删除CacheStorage不等于删除localStorage，但仍可能误删同源其他应用公开缓存。

**建设目标**：只清自己的旧缓存，保留外部命名空间；更新状态对用户可见。
**失败边界**：不能把删除全部缓存作为新安装的普遍惯例。
**验收**：造一个非本项目缓存和两代本项目缓存，升级后只旧本项目缓存被删除。
**任务关联**：[T-CACHE-01](12-ai-execution-tasks.md#t-cache-01)。

### 5.2 请求分类

| 请求 | 当前策略 | 错误边界 |
| --- | --- | --- |
| 非GET或非同源 | 不接管 | 不缓存评阅POST或跨源请求 |
| 页面navigate | 网络优先，成功写缓存；网络失败查请求缓存再index | 保留站内深链离线入口，但不是服务器路由实现 |
| script/style/worker | 网络优先；失败查缓存 | 未缓存模块首次离线仍会失败 |
| 其他同源GET | 已有缓存先返回，并后台刷新；无缓存等待网络 | JSON和图片可能先看到旧缓存版本 |

不要把它统一写为“cache-first全离线”或“所有资源network-first”。
后台刷新失败被吸收不等于新内容已到达；内容版本和缓存版本需要可解释。
给数据添加新字段时，要考虑旧JSON与新JS暂时并存，不只核对入口版本。

### 5.3 首次离线覆盖

预缓存包含入口、核心图式逻辑、核心两份JSON、主要背景、本地vendor和若干工具模块。
学习/黄历等全部可选页面数据不都在首装清单中。
访问过某模式后，动态模块与数据请求可进入缓存；首次断网进入从未下载的模式不能承诺成功。
PWA安装清单的存在不证明所有浏览器、所有设备已允许安装。
Service Worker需安全上下文（HTTPS或localhost例外）；普通局域网HTTP不能直接保证离线控制。
旧Windows或静态托管版本的缓存不能当当前工作区离线证据。

**建设目标**：说明“哪些已可离线”，未缓存时显示明确原因和联网重试入口。
**失败边界**：离线/资料未下载与内容损坏分别提示，不清学习数据。
**验收**：首次在线只进星图后断网、先学习后断网、更新中断、旧缓存升级各自记录结果。
**任务关联**：[T-CACHE-02](12-ai-execution-tasks.md#t-cache-02)。

## 6. 三层存储的故障恢复

| 层 | 可清理范围 | 不可假定的能力 |
| --- | --- | --- |
| 内存状态 | 重绘/重开层、重试模块、重新加载页面 | 未保存草稿不能保证刷新恢复 |
| CacheStorage | 经限定的本项目公开资产缓存 | 不能替代个人备份，不能默认全源删除 |
| localStorage | 仅明确用户数据操作或经过验证的迁移 | 不是数据库事务，无跨origin自动复制 |

readJson容错返回fallback，只说明读取失败，不等于用户从未学习。
新写入函数返回保存结果，所有用户可感知事实必须消费此结果。
正式深读的成就/复习卡若存储失败，应说明阅读仍可继续、记录未保存。
备份导入会尝试回滚，但回滚也可能失败；需要可见反馈而不是“绝对安全”的承诺。
导出可能超过1MiB而导入拒绝，是当前需要修复的容量不对称。
大量笔记和成就processedKeys长期增长需估量，不得通过静默删历史解决。

**验收**：禁用存储、配额异常、坏JSON、导入中途失败、回滚失败分别可复现。
**任务关联**：[T-SAVE-01](12-ai-execution-tasks.md#t-save-01)、[T-BACKUP-01](12-ai-execution-tasks.md#t-backup-01)、[T-BACKUP-02](12-ai-execution-tasks.md#t-backup-02)、[T-CAPACITY-01](12-ai-execution-tasks.md#t-capacity-01)。

## 7. 绘制预算与可观测性

### 7.1 WebGL层

[celestial-stage.js](../../web/js/celestial-stage.js) 的 `celestialPixelRatio()`：

```text
ratio = min(deviceRatio, lowPower ? 1 : 1.5, sqrt(5_000_000 / max(1,width*height)))
```

约500万是此WebGL backing-store预算，不是整个网页所有Canvas纹理的总内存保证。
大屏高DPR降低像素比；不能为截图更锐利移除预算并声称没有成本。
目标帧率：探索45、普通模式24；低功耗探索20、普通12。
hidden或减少动态时持续帧率目标0，通过需要时单帧绘制给稳定场景。
这些是代码预算值，不是本轮已测得所有设备稳定达到的FPS。

### 7.2 Canvas层

[star-map.js](../../web/js/star-map.js) 的 `chooseRenderFps()`：
减少动态10；拖动或cameraDistance大于0.5时60；其他探索30、普通15。
减少动态下10是允许静态重绘的预算，不是应继续让星点、标签和镜头运动。
D3布局、呼吸、流星、轨迹等在减少动态下应收敛为稳定状态。
WebGL的0与Canvas的10不能被文档合并为“所有画布零重绘”。
星图复用预渲染纹理、文字测量缓存和标签布局缓存，避免每帧完整重算。
保留重要标签优先级，性能降级不得变成当前卦名不可读或关系证据消失。

### 7.3 性能建设目标

- 记录可观察的RAF/绘制次数、标签布局次数、纹理重建次数和WebGL像素数。
- 首屏只载核心，其他模块按需，失败Promise可重试。
- resize/缩放/主题变化才在必要时重建纹理，不在常规帧里分配大图。
- 长会话反复开关阅读和工具后，监听与RAF不持续增长。
- 低功耗场景降低氛围成本，核心阅读和点击反馈保持明确。
- 采样记录设备/浏览器/视口/DPR/模式，不能只给没有条件的“性能已优化”。

**失败边界**：以减少星数解决问题前，确认真实瓶颈是绘制、标签、D3、纹理还是DOM。
**验收**：连续拖动、快速选卦、展开工具、深读停留、后台恢复与大屏DPR分别采样。
**任务关联**：按总册中对应星图/质量任务执行；长期存储容量另归 `T-CAPACITY-01`。

## 8. 暂停、恢复与销毁

Canvas与WebGL使用暂停原因集合；原因包括可见性、模式、阅读/面板和工具等。
同一暂停可重复设置，恢复只删除自己的原因，其他原因存在则继续暂停。
WebGL异步创建时，入口会回放已经存在的暂停集合，避免刚加载就从遮罩后开动。
浏览器隐藏再回来，若深读仍开，不得无条件恢复星空。
工具关闭再回来，若仍在手机快读，不得恢复被阅读暂停的绘制。
减少动态偏好在运行中改变，要同步终止过渡和布局运动，不只改CSS动画。

destroy清RAF、监听、图形geometry/material、renderer；DOM移除不是资源释放证明。
pagehide对bfcache保留路径与普通离开有不同处理，不可用一次销毁破坏恢复。
WebGL context丢失与初始化失败需要退到Canvas/正文，不能只留空背景。
**验收**：遮罩A→深读B→关A→仍暂停→关B→按可见性恢复；再重复10轮检查计数。
**失败边界**：组件清理不得全局移除别人监听，不得创建第二个StarMap掩盖坏状态。

## 9. 减少动态、无障碍与降级

减少动态时直接呈现稳定布局；首入演出、自动巡天、镜头推进、流星和呼吸应停止或即刻完成。
操作与正文不因取消演出而不可用；不能等动画end事件才绑定按钮。
WebGL失败保留Canvas选择、文字关系、快读/深读、笔记和返回。
Canvas的等价文字关系入口也是键盘/辅助技术路径，不能为了简洁删掉。
手机模态要隔离背景并限制焦点；桌面非模态快读仍允许星图操作。
可访问性细节另见 [界面与无障碍](07-interface-accessibility.md)。

当前真机、屏幕阅读器和真实浏览器200%缩放尚无完成证据。
390px模拟触控不是Android/iOS真机；DOM/ARIA测试不是读屏；640px等效窄视口不是真实200%。
**验收**：记录真实设备型号、系统、浏览器、缩放操作方法、读屏软件和操作路径。
**失败边界**：证据缺失要标未验证，不以自动脚本通过替代。

## 10. 可执行验收清单

### 10.1 安全与隐私

1. 用隔离浏览器创建虚构笔记和复讲，不加载真实用户备份。
2. 在线完成普通学习，查看网络，仅有公开同源资产，无自动评阅POST。
3. 主动提交评阅，检查字段与 [接口专题](02-architecture-services.md) 一致。
4. 注入显示用尖括号/引号字符串，确认只呈现文本，无脚本执行。
5. 导出备份，确认只有11键白名单与用户明确保存的数据。
6. 确认仓库、发布目录、截图中无模型密钥和私人问题。

### 10.2 离线与升级

1. 新profile在线仅进入星图，等待SW控制，记录预缓存键。
2. 断网重载星图与合法深链，核对可缓存的核心能力。
3. 进入此前未下载的学习/黄历，核对失败提示而非假称全离线。
4. 联网访问上述模式，断网重载，核对动态缓存覆盖。
5. 添加非项目命名缓存，升级测试 `T-CACHE-01` 的保留结果。
6. 升级中让一项precache失败，核对旧可用版本和用户数据仍可恢复。
7. 核对HTML/CSS/JS/SW同代，不凭刷新一次就宣布缓存问题已解决。

### 10.3 绘制与故障

1. 记录1440×1024、1280×720、768×1024、390×844和320px场景。
2. 大DPR核对WebGL实际backing-store像素；预算只计算该层。
3. 快读→深读→后台→前台→返回，核对多个暂停原因。
4. 开减少动态，等待稳定后比较相邻帧，核对视觉不再运动。
5. 禁用WebGL并重新加载，完成Canvas选卦、正式深读和返回。
6. 禁用存储，在正式深读、保存笔记、考校和导入时核对失败反馈。
7. 反复开关阅读与工具，核对监听、RAF、纹理与内存无持续泄漏趋势。

### 10.4 自动化命令与结果登记

根目录可运行 `npm run check`、`npm run test:unit`、`npm run validate`、`npm run test:e2e`。
