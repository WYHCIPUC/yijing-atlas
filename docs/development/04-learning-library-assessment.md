### 1.1 术语与不变量

- 课程：25个稳定lessonId的学习单元；阶段L1—L5与课程ID不得因改标题而重编号。
- 浏览：已打开课程或对应资料，不等于已经掌握，不等于完成深读。
- 课后小试：某一课的题目集合；不同于主导航“测验”的自由随机题。
- 抽查：跨已浏览课程的记忆检查；考评：指定阶段的综合题。
- 复讲：用自己的话说明一课；本地要点自评是自我报告，不能声称机器已理解并客观评分。
- 卦象复习卡：每卦一张间隔卡；课程题目薄弱项不能无依据地塞入某个卦码。
- 正式阅读：沿用阅读专题的深读定义；课程浏览与深读成就分别记录。
- 全部课程开放；测验、成绩、复习、印章不能成为强制锁课、体力或付费门槛。
- 本轮不增加账户、排行榜、云端进度同步，不改原典、历法与六位码规则。

### 4.2 目标规格

- 学程保留五阶段、稳定课程ID、开放规则和主干/旁支来源说明；不因未通过前课禁用后课。
- 每门课明确学习目标、前置知识建议、材料来源、练习方式与完成标准。

- “读”展示实际原文或资料引用；“解”标项目解释；“用”标现代参照和使用边界，不能混成原典。
- 六十四卦范围课必须列出范围内每卦和明确研读入口；打开具体卦按阅读专题携带lessonId/section。

- 返回课程目录恢复原阶段和滚动；返回今日不清掉待继续位置。
- 课程不存在、引用条目缺失或数据集失败时显示具体局部错误与可返回动作；不拿第一课内容替代。
- 来源未校验显示待校验；未发布注疏不成为可读的正式材料。
- 点完成阅读只进入小试，不直接宣称掌握；成绩、浏览和深读是三种独立证据。

## 6. 小试、抽查与阶段考评

### 6.1 当前事实

课后小试默认3题，抽查默认5题，阶段考评默认10题；选项在session内打乱。
抽查有已浏览记录时从这些课选题；当前零浏览记录会回退全题库，页面也未阻止开始。目标“先学一课”尚未实现，由T-LEARN-05补边界。题目不足时使用实际可用数量；完全无题显示空态。
未答完交卷会提示首个未答题并聚焦；结果显示正确数、分数、解释和来源。
小试写每课bestScore、attempts、lastStudiedAt；抽查与考评追加历史，分别最多80条。
课程成绩写入后，仅lesson类型目前接入课程成就事件；exam与综合证据接入见成长专题。

### 6.2 字段、验证和正常流程

- session有明确kind、课程/阶段、题目集合和本轮稳定标识；后续渲染不重新随机换题。
- 题目有稳定id、lessonId、prompt、options、answer、explanation和source；显示文本和判分值分离。
- 仅接受本session选项中的值；空答案提示未完成，非法值按未答处理，不因DOM篡改取得分数。
- 小试必须选合法课程；阶段考评必须选合法levelId；抽查没有已浏览课程时说明先学一课。
- 交卷后锁定本轮提交；重试保存复用同session标识，重新练习才创建新session。
- 同一session不能因重复submit、双击或恢复结果视图重复增加attempts与成就证据。
- 取消回考评中心；取消不写成绩，执行默认不持久化未提交选项。
- 结果可返回原课、查看错误依据或开始下一项；始终只有一个主行动。
- 切模块/刷新会失去未提交卷，除非后续明确加入草稿恢复；界面不能声称已保存答卷。

### 6.3 状态与失败处理

2026-10-25最新增量：session、选项校验、未答定位、原轮保存重试、零浏览抽查空态、修习谱回补及正式processedAssessmentIds契约已提交25fa12a；[小试/抽查浏览器专项](evidence/2026-10-25-assessment-session-browser.md)9/9与[整合验证](evidence/2026-10-25-contract-input-integration.md)通过，T-LEARN-05完成本地验收。不能外推全部阶段考评入口已完成；数据边界见[数据专题](08-data-storage-content.md)，剩余见[清单](REMAINING-WORK-AND-GOAL.md)。本节上方原“零浏览回退”属于首次快照，已由空态修复取代。

- 加载：题库依赖资料未完成前展示忙状态，不能以零题满分结算。
- 空：没有可用题，说明原因并提供返回学习；不能只留下无返回的空白区域。
- 错误：题目引用失效跳过并记录诊断；不足最低可评分题数时终止该session而非乱配答案。
- 保存失败：结果照常展示，明确本轮成绩/薄弱项/成就哪些未保存，可重试。
- 当前成绩与历史最佳同时可区分；本轮低分不会抹掉历史最佳，但必须反映新薄弱项。
- 键盘使用fieldset/legend和radio原生操作，焦点不被异步入场动画拉回页首。
- 触控选项需整行可点，长答案自然换行，不依靠小radio点位。

### 6.4 验收

- Given 第2题未答，When 交卷，Then 提示第2题并定位，不写任何成绩。
- Given 同一卷连续两次submit，When 第一次已结算，Then attempts和事件各只增加一次。
- Given 仅两道有效题，When 创建默认3题小试，Then 明示实际2题并以2为分母。
- Given 存储写入失败，When 交卷，Then 分数可读且显示未保存，不假报已进入复习。
- Given 取消答卷，When 回中心，Then 不新增activity以外的成绩证据；activity是否记取消须遵循全站活动定义。

- 页面只调用`createQuizAttempt`和`submitQuizAttempt`，不再在选项点击中分别写统计或猜测成就。首次有效答案绑定本轮身份；同attempt重试只补失败部分，不换题、不换答案、不重复累计成功记录。切模块或刷新后不承诺恢复该内存对象。
- 回执分别报告累计统计、具体弱项、卦象复习卡、学习活动、成就、旧摘要六项；不适用项不显示。任一适用项失败时保留可读结果和“重试保存未完成的记录”；反馈滚入附近视区，失败时聚焦重试，成功时聚焦下一步。
- 具体弱项与其quizAttempts回执在学习键内一次保存；六项跨键无事务保证。部分成功时不能写成“全部已保存”，不能为了补成就重新累计统计或错误次数。
- 同一规则/目标/版本的明确回练有效答对，且旧弱项存在未解决错误证据、当前回执保存成功后，才能显示该项已纠正及尝试quiz.recovered。随机答对、另一题型/方向答对、仅打开资料、旧摘要练习均不替代原薄弱规则纠正；没有新增跨天或24小时等待算法。
- 同题号但引用版本等七字段不一致时保留旧弱项，回执可成功保存但结果为`reference-mismatch`；页面明确“已保留原记录”，不把`saved=true`误写成“已纠正”。
- 旧摘要正确练习只清该旧码摘要，不删除具体弱项、不发新的具体纠正成就；答错卦题可沿原规则加入卦卡。术语答错只进术语弱项，不造六位码或卦象卡。
- 答案选择和候选内容只保留在内存；持久化仅为公开引用、正确与否、必要时间/身份和保存回执，不存私人自由文本。完整字段与幂等约束见[数据专题§7.1.6](08-data-storage-content.md#quiz-attempt-contract)。

以上实现未替代T-LEARN-03的全模块四段反馈、间隔卡评分重试和复讲生命周期任务，也未宣称真机、读屏、真实200%或长期容量已验证。

### 10.2 目标与执行默认

- 每题有稳定questionId或本轮标识、type、target、answer、options和解释出处；显示正确答案与判分键分离。
- 当前四卦题必须保留；上下卦拆解若加入，作为明确新题型单独覆盖，不在文档先宣称已有。
- 错题按题目规则和目标归并，保留错误类型；不能仅答对同卦任意题就清除其他规则错误。
- 黄历术语错题接相应课程/术语温习队列，不映射成任意卦卡。
- 累计total每个有效作答一次；重复点击已禁用选项、重播反馈不计第二次。
- 保存失败给具体反馈；统计、错题、复习卡、活动和成就不能用一个虚假的“保存成功”统称。
- 下一题生成新题，返回随机/错题模式清楚；最后一道错题纠正后明确返回随机。
- 选项不足或数据异常给无可用题和返回学习，不让currentQuiz为null后继续访问属性。
- 无结果期间不播放完成音；答错音不得成为羞辱或警报，具体音色仍受声音专题门禁。
- 刷新进入新题，已有已保存统计和错题仍在；不声称恢复未答题目。

### 10.3 验收

- Given 错卦辨识答错，When 回练答对同卦的卦名题，Then 原错卦薄弱项不被误清。
- Given 黄历术语答错，When 查看温故，Then 有对应术语/课程任务，没有虚假hexCode。
- Given 同一选项重复点击，When 查看统计，Then total只增加一。
- Given 最后一项有效错题纠正，When 下一步，Then 明确提示回随机测验而非空循环。
- Given 断网但资料已缓存，When 继续题目，Then 本地判分可用，不发智能请求。
- Given 统计已保存而弱项/卡片保存失败，When 在原页面重试，Then 原答案不变，统计不再加一，反馈仅将实际成功部分改为已保存。
- Given 术语原规则回练，When 查看原术语再返回，Then 展开真实条目并返回相同规则；打开来源本身不增加错误次数或纠正证据。
- Given 旧版本同题号或旧卦码摘要，When 完成当前练习，Then 旧版本保留/旧摘要单独处理，不冒称原具体错误已纠正。
- Given 切换模式后旧回调才执行，When 检查新页面，Then 焦点、导航和持久化没有被旧视图改变。

## 11. 统一修习反馈：T-LEARN-03

2026-10-25工作区已由 [learning-feedback.js](../../web/js/learning-feedback.js) 统一课程考评、复讲、间隔复习、自由测验及解卦自评的结果结构。实际段落文案为“本次结果、判断依据、学习记录、下一步”；一个主行动、最多两个次行动由共用渲染器约束。调用页面仍负责各自判分、自评、保存与导航；渲染反馈本身不写数据、不触发成就、不移动焦点，也不接收未转义的用户或模型HTML。

已有实现不等于整卡验收完成。源码身份、专项范围、完整门禁、历史失败及提交状态统一记录在[学习反馈交接](evidence/2026-10-25-learning-feedback-integration.md)，不在本节叠加不同快照的通过数。

| 固定段落 | 必须回答 |
| --- | --- |
| 本次结果 | 本题/本轮表现；不把单次答对等同永久掌握。 |
| 依据辨析 | 正答、推导、原课或典籍出处；自评说明依据来自用户自述。 |
| 记录变化 | 哪些成绩、薄弱项、卡片和证据真实保存，下次温故时间；保存失败单列。 |
| 下一步 | 一个主行动，最多两个次行动，直接进入对应任务。 |

**当前语义与操作边界**：测验显示本题判分，间隔复习明确“基于你的自评”，复讲区分智能评阅和要点自评；解卦现有五项勾选仍是自我报告，不能借四段呈现冒称T-DIV-02的结构化挑战已完成。学习记录段分别说明已保存与未保存项；失败优先呈现可见状态或重试行动，成功定位结果或下一步。只给短状态节点设置播报语义，不把整张反馈或长卷放进 `aria-live`。

来源动作沿用真实入口：复讲回本轮原课；考评可进入原课/原题回练；测验术语返回原条目；间隔卡可核对本卦卦辞并回反馈。打开依据不代替作答、纠正或保存，失败退出也不自动补写。复讲正文、请求返回及未保存重试状态不跨刷新恢复；其他跨模块来路和占筮正式读经的后续要求仍归原任务。

- 自由题用“本题答对/本题未答对”；复习用“基于你的自评”；解卦用结构与证据层描述。
- 反馈嵌在当前结果后，不用庆祝模态遮住答案；成绩变更后先让用户看依据再展示非阻挡成就。
- 正常色配文字/真实图标；不用单一红绿或emoji作为唯一信号。
- 键盘提交后定位反馈标题/下一步，aria-live播报短结果；不要一次朗读整张长卷。
- 不把旧原文完整复制到反馈中；引用稳定来源并可定位原课，缺出处明确待校验。
- Given 答错且薄弱项保存失败，When 看反馈，Then 分别说明答案与未保存，不显示已安排温故。
- Given 自评选择能清楚复述，When 看反馈，Then 标自评而非机器判定正确。
- Given 课程考评结束，When 触发成就，Then 原答案仍可读，不被遮挡或自动跳走。

## 12. 学习记录、成长称谓与隐私

当前掌握度为浏览10、小试最佳35、抽查20、复讲最佳15、阶段考评20；算法变化须另立版本，不偷改旧分。
