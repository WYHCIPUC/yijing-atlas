### 1.1 术语与不变量

- 课程：25个稳定lessonId的学习单元；阶段L1—L5与课程ID不得因改标题而重编号。
- 浏览：已打开课程或对应资料，不等于已经掌握，不等于完成深读。
- 课后小试：某一课的题目集合；不同于主导航“测验”的自由随机题。
- 抽查：跨已浏览课程的记忆检查；考评：指定阶段的综合题。
- 复讲：用自己的话说明一课；本地要点自评是自我报告，不能声称机器已理解并客观评分。
- 卦象复习卡：每卦一张间隔卡；课程题目薄弱项不能无依据地塞入某个卦码。
- 正式阅读：沿用阅读专题的深读定义；课程浏览与深读成就分别记录。
- 全部课程开放；测验、成绩、复习、印章不能成为强制锁课、体力或付费门槛。
- 本轮不增加账户、排行榜、云端进度同步，不改原典、历法与六位码规则。

## 3. 今日修习、推荐与恢复：T-LEARN-01

### 3.1 当前事实

今日页已有“继续研习”主卡、到期复习数、小试数、连续学习天数和修习谱入口。
推荐器实际先找第一门未浏览课，全部浏览后按最低bestScore和较早学习时间排序。
它没有使用到期卡、未完成课程位置、跨题型薄弱项或解卦任务做完整优先级。
“继续未完成，再补薄弱项”的页面文案目前比实际算法更强。
当前切换学习子页会重绘、回顶部；退出学习再进入默认今日页，没有跨会话续读位置。

### 3.2 目标规格与执行默认

1. 继续用户明确开始但未完成的最近课程。
2. 没有继续项时，处理已到期的复习任务。
3. 没有到期项时，处理已检出的课程/测验薄弱项。
4. 然后进入下一节未浏览课程。
5. 全部课程已浏览且没有以上任务时，推荐复讲或已有解卦实践。

- 主卡只保留一个主要行动，注明推荐原因、任务类型和完成标准；卡片按钮应真实进入所推荐的任务。
- 执行默认“未完成课程”为已进入课程且未完成本轮小试；正在进行的阅读有最近位置时优先续读。
- 欢迎“零基础开始”的目标直接打开l1-1，不经过推荐；当前只进今日修习是待补差距。常规“继续研习”仍走推荐队列。
- 完成一轮小试后不继续把该轮视为“未完成”；低分转薄弱项，不用“未完成”反复强推。
- 到期卦象卡和课程薄弱项是不同任务类型；返回动作须知道来源。
- 同级排序依次用最近明确学习行为、到期时间、稳定课程序；不得每次渲染随机变主卡。
- 恢复记录只存lessonId、sectionId、scroll位置与时间等最小呈现信息，不存课程正文副本。
- 与数据专题约定新增可选恢复字段和迁移；旧记录缺字段时正常推荐，不覆写历史成绩。
- 本地存储失败：任务仍可打开，提示本次无法记住位置；不能阻断学习。
- 刷新后只能恢复已保存的课程位置；未提交答案或复讲草稿不默认偷偷持久化。

### 3.3 输入与验收

- 鼠标/触控点击主卡进入具体课程、复习或薄弱题；不能只切到一个泛首页。
- 键盘Tab可到主行动和次入口；改变推荐不强行抢焦点。
- 空态：无学习历史推荐第一课；全部任务完成显示自由温习，而非索引00或空白标题。
- Given 有未完成课且有到期卡，When 打开今日，Then 继续该课为主，到期复习仍可见为次入口。
- Given 没有未完成课且两卡到期，When 打开今日，Then 主行动进入到期复习，并说明2项到期。
- Given 某课阅读到“解”，When 退出刷新再继续，Then 定位该课可恢复位置，不新增第二份浏览成绩。
- Given 存储被禁用，When 学习一课，Then 内容正常，保存提示诚实，不显示已续存。

## 4. 五阶学程和课程正文

### 4.1 当前事实

课程全部可浏览；主干与三旁支已有说明；学程显示浏览、小试、复习、自由测验正确率等概览。
正文采用引→观→读→解→用→试；首课有阴阳概览，其他课直接进入阅读。
打开课程就调用markLessonViewed并记录活动；该行为仅证明打开过。
L2课程读取指定卦序范围，但主要正文仍是范围介绍和通用六步；缺逐卦研读目录及对应经文上下文链路。

### 4.2 目标规格

- 学程保留五阶段、稳定课程ID、开放规则和主干/旁支来源说明；不因未通过前课禁用后课。
- 每门课明确学习目标、前置知识建议、材料来源、练习方式与完成标准。
- 正文连续纵向阅读，不做拟物翻页；正文18px/1.9、最大约720px，出处边注在窄屏按需展开。
- “读”展示实际原文或资料引用；“解”标项目解释；“用”标现代参照和使用边界，不能混成原典。
- 六十四卦范围课必须列出范围内每卦和明确研读入口；打开具体卦按阅读专题携带lessonId/section。
- 首课概览“继续研习”进入同一课程正文，不把概览开关当作两次完成。
- 返回课程目录恢复原阶段和滚动；返回今日不清掉待继续位置。
- 课程不存在、引用条目缺失或数据集失败时显示具体局部错误与可返回动作；不拿第一课内容替代。
- 来源未校验显示待校验；未发布注疏不成为可读的正式材料。
- 点完成阅读只进入小试，不直接宣称掌握；成绩、浏览和深读是三种独立证据。

### 4.3 验收

- Given L2第一段课程，When 展开材料，Then 乾至比八卦均可按序进入，返回后仍在原课程。
- Given 开放课程目录，When 尚未学L1就进入L4，Then 可以阅读并说明建议前置，不出现锁链。
- Given 某资料字段缺失，When 进入该课，Then 显示资料待补，不生成貌似真实的引用。
- Given 窄屏长课文，When 键盘切章节，Then 目录、正文和边注都可达且无横向溢出。

## 5. 典籍书库与资料引用

当前四书库为八卦、十翼、象数、历法；入口和内容均在学习模块内，不是新主导航。
八卦资料进入即记l1-4浏览；其他资料details打开时按refs/category匹配课程并记浏览。

- 八卦需显示三爻符号、名称、自然之象、卦德及来源；符号仍按底到顶数据绘制。
- 十翼按经传身份组织；文言、系辞等名称和段落不可被项目解释覆盖。
- 象数条目需说明流派、年代或争议范围；河洛、纳甲、八宫、消息不能写成普适自然定律。
- 历法术语页与日期黄历工作台分开；前者学习定义，后者展示某一天计算结果。
- 每栏小节检验明确对应lessonId；资料浏览不自动赋给所有相关课程“已完成”。
- 资料无对应小试时保持阅读入口，不绘制禁用且无解释的占位按钮。
- 搜索/筛选若新增，只查询当前真实条目；空态说明匹配不到，不填造新术语。
- 资料展开/收起使用原生details或等价aria-expanded，键盘Space/Enter可操作。
- 返回书库恢复原类别；打开深读的引用须保留书库来路。
- Given 展开某象数条目，When 查看浏览记录，Then 只影响匹配课程且不计正式深读。
- Given 资料尚待校验，When 查看原文与解释，Then 两层标记持续可见。

## 6. 小试、抽查与阶段考评

### 6.1 当前事实

课后小试默认3题，抽查默认5题，阶段考评默认10题；选项在session内打乱。
抽查有已浏览记录时从这些课选题；当前零浏览记录会回退全题库，页面也未阻止开始。目标“先学一课”尚未实现，由T-LEARN-05补边界。题目不足时使用实际可用数量；完全无题显示空态。
未答完交卷会提示首个未答题并聚焦；结果显示正确数、分数、解释和来源。
小试写每课bestScore、attempts、lastStudiedAt；抽查与考评追加历史，分别最多80条。
课程成绩写入后，仅lesson类型目前接入课程成就事件；exam与综合证据接入见成长专题。

### 6.2 字段、验证和正常流程

- session有明确kind、课程/阶段、题目集合和本轮稳定标识；后续渲染不重新随机换题。
- 题目有稳定id、lessonId、prompt、options、answer、explanation和source；显示文本和判分值分离。
- 仅接受本session选项中的值；空答案提示未完成，非法值按未答处理，不因DOM篡改取得分数。
- 小试必须选合法课程；阶段考评必须选合法levelId；抽查没有已浏览课程时说明先学一课。
- 交卷后锁定本轮提交；重试保存复用同session标识，重新练习才创建新session。
- 同一session不能因重复submit、双击或恢复结果视图重复增加attempts与成就证据。
- 取消回考评中心；取消不写成绩，执行默认不持久化未提交选项。
- 结果可返回原课、查看错误依据或开始下一项；始终只有一个主行动。
- 切模块/刷新会失去未提交卷，除非后续明确加入草稿恢复；界面不能声称已保存答卷。

### 6.3 状态与失败处理

- 加载：题库依赖资料未完成前展示忙状态，不能以零题满分结算。
- 空：没有可用题，说明原因并提供返回学习；不能只留下无返回的空白区域。
- 错误：题目引用失效跳过并记录诊断；不足最低可评分题数时终止该session而非乱配答案。
- 保存失败：结果照常展示，明确本轮成绩/薄弱项/成就哪些未保存，可重试。
- 当前成绩与历史最佳同时可区分；本轮低分不会抹掉历史最佳，但必须反映新薄弱项。
- 键盘使用fieldset/legend和radio原生操作，焦点不被异步入场动画拉回页首。
- 触控选项需整行可点，长答案自然换行，不依靠小radio点位。

### 6.4 验收

- Given 第2题未答，When 交卷，Then 提示第2题并定位，不写任何成绩。
- Given 同一卷连续两次submit，When 第一次已结算，Then attempts和事件各只增加一次。
- Given 仅两道有效题，When 创建默认3题小试，Then 明示实际2题并以2为分母。
- Given 存储写入失败，When 交卷，Then 分数可读且显示未保存，不假报已进入复习。
- Given 取消答卷，When 回中心，Then 不新增activity以外的成绩证据；activity是否记取消须遵循全站活动定义。

## 7. 课程错题与温故闭环：T-LEARN-02

### 7.1 当前差距

课程小试、抽查、考评目前只保存results摘要，没有调用卦象复习引擎或自由测验错题本。
课程文案“答错会加入复习安排”因此不成立；不能仅改文案掩盖已确认的学习闭环要求。
自由测验错题只以卦码存储，无法直接承载理论题、术语题与经传出处题。

### 7.2 目标与执行默认

- 建立课程薄弱项队列，按questionId归并，同时保留lessonId、来源session、最近答错时间和待温习状态。
- 执行默认新增数据纳入学习记录的可选weakQuestions集合；具体版本、校验和迁移与数据专题一致。
- 队列保存题目引用和必要事实，不复制整份课程原文；题库升级后引用失效可退回对应课程温习。
- 同一session同一题只入队一次；再答错更新最近证据，不无限新增同义项。
- 有明确hexCode的卦题可同时添加卦象卡；纯理论或术语题不得强造六位码。
- 队列入口在今日推荐、温故和考评结果中可达，任务类型清楚标“课程温习/卦象间隔卡”。
- 清除薄弱项需完成对应有效回练；只打开原课不视为纠正。
- 答对一次描述“本轮已纠正”，不能声称永久掌握；后续调度可继续按证据安排。
- 保存失败时反馈中不显示“已加入”；重试使用原session/question去重。
- 旧无弱项数据正常运行，不清除已有自由错题本、复习卡或成绩。

### 7.3 验收

- Given 课程理论题答错，When 查看温故，Then 有该课程题/课程温习入口，不出现随机卦卡。
- Given 同一题连续两次答错，When 查看队列，Then 一项待温习并保留最近证据。
- Given 题库移除旧题，When 打开该薄弱项，Then 回对应课程并说明题目已调整，不崩溃。
- Given 重试一次保存，When 查看队列和卡，Then 不产生两项同题或重置原有卡到期日。

## 8. 复讲、自评与可选智能评阅

### 8.1 当前事实

复讲按课程选择，textarea maxlength为3000；本地可查看要点，自评40/60/80/100并保存mode=self。
本地自评不要求提交正文，也没有机器检查内容真实性；必须称“自评”，不能改写为客观达成。
智能按钮只有配置同源代理路径后启用；要求至少20字，请求15秒超时，异常退回要点自评。
请求为POST，credentials为omit，携带schemaVersion=1、task、lesson的id/title、rubric和response。
返回需score为0—100有限数、summary为字符串、strengths/improvements为字符串数组；最多展示各四项。
当前仓库只有前端调用协议，没有可直接宣称上线的智能评阅后端。

### 8.2 目标规格

- 提交前明确文本将发送到所配置的同源服务；不自动发送笔记、起卦问题或其他课程记录。
- 本地自评保持可独立完成；不配置服务、离线、超时或格式错误时仍可用。
- 配置只接同源相对路径，拒绝协议相对和外域地址；模型密钥不得写进前端或导出配置。
- 用户输入在3000字范围内，智能提交trim后不足20字给就地错误并聚焦，不预先增加成绩。
- 提交期间禁用同次重复提交；离开页面要避免旧响应覆盖新课或新复讲会话。
- 返回后标“智能评阅”或“基于要点的自评”，展示依据与局限，不写“已证明完全掌握”。
- 成功写入复讲成绩与活动；写失败提示未保存；重试保存不再次调用收费服务。
- 本轮默认复讲正文仅在内存，保存的是分数、mode、课程和时间；不将正文偷偷写入备份。
- 不要求建设云端服务来完成静态本地交付；若未来接服务，按架构专题单独授权、开发和验收。

### 8.3 验收

- Given 没配置服务，When 打开复讲，Then 智能按钮禁用且本地要点和自评可用。
- Given 文本不足20字，When 智能提交，Then 不发送请求、不写分数。
- Given 服务超时/500/不合协议，When 返回，Then 显示具体失败并给要点自评，不伪造点评。
- Given 旧请求未返回用户已切课，When 旧响应到达，Then 不写到新课程或覆盖新输入。
- Given 自评100，When 查看记录，Then mode明确为self，不能显示“系统客观评分100”。

## 9. 卦象间隔复习

### 9.1 当前事实

一卦一卡；首次引入卡和已复习卡可入队，不给新用户自动创建64张到期卡。
到期按due<=当前时间判断；一张直接开卡，多张最多展示20个；完成后重新取队列。
翻面前是卦象与上下卦，翻面后卦名/卦辞；翻开后才显示自评按钮。
简化间隔序列为0、1、2、4、7、15、30、60天；不是完整自适应SM-2参数系统。
忘了退到stage1且lapses加一；模糊保持至少stage1；记得stage加一并封顶。
提交写卡、活动和review.completed；状态提示预计几日后或保存失败。

### 9.2 目标规格

- 自评文案改“暂未想起/有些模糊/能清楚复述”，明确“基于你的自评”。
- 自评不是正确/错误判题；第二轮声音未确认前保持安静，不播放成功或失败音。
- 先主动回忆，再翻答案；未翻开不显示可提交评分，防止误触。
- 评分值只接受0/1/2，非法值不默认当“记得”；本轮卡提交有稳定标识。
- 同一卡同轮快速双击只增加一次reps和一次review事件；返回队列后下一轮是新提交。
- 保存失败保留可读答案和原评分选择；重试只写未成功部分，不重复推进stage。
- 当前算法调度作为兼容底线；未经专项批准不顺手更换间隔算法或批量重算旧due。
- 空队列区分尚无内容与今日完成，分别给开始学习或继续探索；不能暗示所有课程已经掌握。
- 关闭/切模块不自动评分；刷新后读取已保存卡，不保存翻面动画。
- 鼠标触控整张翻面，键盘Enter/Space可翻；评分后焦点进入反馈或下一卡标题。

### 9.3 验收

- Given 新用户无卡，When 进复习，Then 空态可从第一课开始，不显示64张未学卡。
- Given due未来且已有卡，When 深读该卦，Then 复习到期不被重置成现在。
- Given 已翻面，When 选择有些模糊，Then 明确自评并说明下次温故时间，不播放判错声。
- Given 同次评分双击，When 检查卡，Then reps只加一；存储失败重试不再加一次。

## 10. 自由测验与错题回练

### 10.1 当前事实

随机卦题包括错卦、综卦、互卦、全称辨卦名；引擎注释的上下卦拆解不在实际题型池。
有历法资料时约20%概率出黄历术语题；黄历题无hex targetCode，当前不进入卦码错题本。
卦题答错将targetCode写错题本并加复习卡；回练答对移除该卦码并写quiz.recovered。
错题本只存卦码，不存具体题型/题干；同卦回练可能变成另一题，不能证明原错误规则已纠正。
答题后全部选项禁用，显示正确项与误选、解释、下一题；累计统计持久化。

### 10.2 目标与执行默认

- 每题有稳定questionId或本轮标识、type、target、answer、options和解释出处；显示正确答案与判分键分离。
- 当前四卦题必须保留；上下卦拆解若加入，作为明确新题型单独覆盖，不在文档先宣称已有。
- 错题按题目规则和目标归并，保留错误类型；不能仅答对同卦任意题就清除其他规则错误。
- 黄历术语错题接相应课程/术语温习队列，不映射成任意卦卡。
- 累计total每个有效作答一次；重复点击已禁用选项、重播反馈不计第二次。
- 保存失败给具体反馈；统计、错题、复习卡、活动和成就不能用一个虚假的“保存成功”统称。
- 下一题生成新题，返回随机/错题模式清楚；最后一道错题纠正后明确返回随机。
- 选项不足或数据异常给无可用题和返回学习，不让currentQuiz为null后继续访问属性。
- 无结果期间不播放完成音；答错音不得成为羞辱或警报，具体音色仍受声音专题门禁。
- 刷新进入新题，已有已保存统计和错题仍在；不声称恢复未答题目。

### 10.3 验收

- Given 错卦辨识答错，When 回练答对同卦的卦名题，Then 原错卦薄弱项不被误清。
- Given 黄历术语答错，When 查看温故，Then 有对应术语/课程任务，没有虚假hexCode。
- Given 同一选项重复点击，When 查看统计，Then total只增加一。
- Given 最后一项有效错题纠正，When 下一步，Then 明确提示回随机测验而非空循环。
- Given 断网但资料已缓存，When 继续题目，Then 本地判分可用，不发智能请求。

## 11. 统一修习反馈：T-LEARN-03

当前课程考评、复习、自由测验和解卦各自生成不同结构；部分反馈只有分数或一句保存提示。
统一“修习反馈笺”是业务和可访问性要求，不等于给旧卡片换背景色。

| 固定段落 | 必须回答 |
| --- | --- |
| 本次结果 | 本题/本轮表现；不把单次答对等同永久掌握。 |
| 依据辨析 | 正答、推导、原课或典籍出处；自评说明依据来自用户自述。 |
| 记录变化 | 哪些成绩、薄弱项、卡片和证据真实保存，下次温故时间；保存失败单列。 |
| 下一步 | 一个主行动，最多两个次行动，直接进入对应任务。 |

- 自由题用“本题答对/本题未答对”；复习用“基于你的自评”；解卦用结构与证据层描述。
- 反馈嵌在当前结果后，不用庆祝模态遮住答案；成绩变更后先让用户看依据再展示非阻挡成就。
- 正常色配文字/真实图标；不用单一红绿或emoji作为唯一信号。
- 键盘提交后定位反馈标题/下一步，aria-live播报短结果；不要一次朗读整张长卷。
- 不把旧原文完整复制到反馈中；引用稳定来源并可定位原课，缺出处明确待校验。
- Given 答错且薄弱项保存失败，When 看反馈，Then 分别说明答案与未保存，不显示已安排温故。
- Given 自评选择能清楚复述，When 看反馈，Then 标自评而非机器判定正确。
- Given 课程考评结束，When 触发成就，Then 原答案仍可读，不被遮挡或自动跳走。

## 12. 学习记录、成长称谓与隐私

当前掌握度为浏览10、小试最佳35、抽查20、复讲最佳15、阶段考评20；算法变化须另立版本，不偷改旧分。
当前存在三套易混称谓：课程五阶、掌握度初闻至通达、成就五阶×三状态；详情见成长专题的统一规则。
学习成绩和自评保存于当前浏览器，分享图不包含；数据导出可能包含个人笔记和历史，需按私人备份处理。
本地AI代理地址可以随备份存在，但模型密钥不允许进入任何前端字段。
备份、导入、迁移、数据清空与存储失败统一使用[数据与内容专题](08-data-storage-content.md)，不另造第二套导入器。
复讲正文与未提交答案默认仅内存；如未来增加草稿保存，必须明示开关和清除边界，不以“方便恢复”为由暗存。
