## 2. 整体设计语言

探索空间使用深蓝黑天幕、有亮暗反差的银河、细银仪器线和分层星群。
铜金集中在当前卦和主行动，朱砂表达已有警示或需要温习的状态。
阅读空间使用星仪外框与暖宣纸正文。
学习、复习、测验和经文使用稳定正文，空间文字只负责图式识别和观察引导。
不为每个模块另造一套品牌、图标风格和高亮语义。

### 2.1 材质使用

| 场景 | 主材质 | 约束 |
| --- | --- | --- |
| 星图探索 | 深色星空 | 银河留暗部，关系与当前卦比普通星亮 |
| 学习研经 | 暖宣纸 | 长文可读，外框墨蓝，不在纸上铺金色小字 |
| 黄历 | 暖纸与深色资料分区 | 时间结构与民俗资料可区分 |
| 转盘、成就 | 哑光铜器 | 用于机构、印记和主操作边缘，不铺满所有按钮 |
| 反馈 | 内嵌暖纸 | 结果先读完，成就不能遮挡本题 |

每屏只能有一个占主导的材质层。
不使用烧焦纸边、茶渍、撕裂、木轴或夸张折痕。
纸张阴影、铜器高光和按下方向沿用统一左上光源。
无字纹理可以是位图，信息必须由真实 HTML、SVG、Canvas 和项目数据绘制。

### 2.2 已确认比例的用途

基线给出的星图/铜器/宣纸比例是视觉重心约束，不是 CSS 必须精确量到百分之一的面积公式。
探索约 70/20/10，学习约 25/10/65，黄历约 35/20/45，转盘与成就约 45/45/10。
当比例与正文可读性冲突时，先保证阅读和操作。
不可为了铜器比例重复叠三套圆环或把纸正文压成细栏。

## 3. 当前主题 tokens 与使用约定

### 3.1 主题文件职责

`web/styles/immersive.css` 是当前沉浸星仪主题入口。
`web/styles/main.css` 仍保留大部分功能布局、旧偏好兼容和历史样式。
入口按当前顺序加载，后者中的旧变量可能被新主题覆盖。
新增样式优先使用现有语义变量和对应组件块，不再文件末尾无限追加覆盖。
删除旧样式之前先检索所有功能页面和断点的依赖。
不得一次性重写 `main.css` 并同时改业务状态。

## 4. 字体、排版、间距与尺寸

### 4.1 字体角色

| 角色 | 当前系统字体栈 | 使用范围 |
| --- | --- | --- |
| UI | Microsoft YaHei UI/YaHei、PingFang SC、Noto Sans CJK SC、Source Han Sans SC、sans-serif | 导航、按钮、状态、表单、目录 |
| 阅读 | Source Han Serif SC、Noto Serif CJK SC、Songti SC、STSong、SimSun、serif | 经文、课程正文、长说明 |
| 展示 | Kaiti SC、STKaiti、KaiTi、Source Han Serif SC、serif | 少量标题和文化意象 |

不为追求笔触给全部按钮使用楷体。
字体缺失时必须有系统回退，不能依赖在线字体才能看清页面。
不从未经许可的现代字库复制字体文件。

### 4.2 字号与行宽

- 长文约 18px、行高 1.9、最大宽度 720px。
- 辅助文字不低于 15px，不能以透明度加小号同时弱化必要信息。
- 目录和来源边注采用 UI 字体及至少 15px。
- 标题按结构层级区分，不用大量同级 36px 口号。
- 中文长词、卦名和全名采用可控换行，避免逐字孤行。
- 卦码和数据值可使用易辨认等宽回退，但不把全部中文变成 monospace。
- 长 URL、文件名和来源字段允许换行，不撑破容器。
- 文字放大不能被定高卡片裁掉。

当前根字号为 17px，历史 CSS 含多种 rem 值和 `!important`。
实现时要检查 computed style，不能只看到 `font-size:18px` 就认为所有内部小字达标。
普通页面正文不要使用金色 12px 字作为主要解释。

### 4.3 间距和控件尺寸

建议沿用 4/8px 基础节律，常见间距 8、12、16、20、24、32、48。
同组内部间距小于组间距，不用每行都另加卡片边框。
常用交互区建议至少 44×44 CSS px。
当前个别宜忌标签为 36px，需要在手机验收中检查相邻间距与点击面积，不宣称全站 44px 已实现。
桌面导航约 72px；窄屏当前约 116px，手机加 safe-area。
按钮文字不得因定高而垂直裁切。
图标 16—20px，与文本光学对齐；关闭按钮通常为 44×44。

## 5. 响应式和设备边界

### 5.1 当前断点

| 范围 | 当前主要行为 | 验收重点 |
| --- | --- | --- |
| >1180px | 完整桌面外壳和阅读布局 | 导航、工具和纸正文不互压 |
| 901—1180px | 桌面压缩布局 | 不把搜索/导航压成不可用 |
| >1100px | 快读身份与处境可用双列 | 正文仍保持顺序与可读 |
| ≤1100px | 目录/出处按需折叠的 JS 规则 | 从桌面缩窄也同步，不仅首次加载 |
| ≤900px | 顶部两行，阅读文档单列，快读 75dvh，模态判断切换 | 焦点/inert 不能互相锁住 |
| ≤600px | 手机工具底部面板、safe-area、紧凑欢迎与阅读 | 核心流程完整 |
| ≤360px | 额外缩窄导航与阅读间距 | 320px 无溢出，无单字列 |

断点是内容适配阈值，不是设备型号识别。
900px 的模态阈值与 1100px 的阅读侧栏阈值不同，不能混成一个 `isMobile`。
CSS 断点和 `matchMedia` 必须对应，改一个时检查另一个。
浏览器缩放会使 CSS 视口变窄，应按同一规则适配。

### 5.2 视觉矩阵

| 视口/条件 | 必须覆盖 |
| --- | --- |
| 1440×1024 | 欢迎、全景、聚焦、快读、深读、功能页 |
| 1280×720 | 常用桌面低高度下控制、阅读和反馈可见 |
| 768×1024 | 平板单列、模态、折叠目录和工具 |
| 390×844 | 手机全旅程、触摸和软件键盘 |
| 320px | 六导航、搜索、表单、阅读、错误无横溢 |
| 真实浏览器 200% | 实际放大条件下功能全部可达 |
| 系统减少动态 | 稳定画面与即时内容 |
| 强制颜色 | 焦点、状态、图标和控件边界可辨 |

640 CSS px 的等效窄视口只证明回流，不代表真实 200% 缩放通过。
手机浏览器模拟只证明模拟环境，不代表真机软键盘、GPU、手势或安全区通过。
设备证据归 `T-A11Y-01`，当前状态保持未验证。

## 6. 页面四状态和工作台容器

### 6.1 状态契约

| 状态 | 主体 | 可操作区域 | 返回 |
| --- | --- | --- | --- |
| 全景 | 银河、卦族、紧凑工具 | 星图和必要控制 | 主导航 |
| 聚焦 | 当前卦、关系目标、摘要 | 星图、关系、研读入口 | Escape 回全景 |
| 快读桌面 | 底部约 46dvh 稳定正文 | 非模态，星图可继续操作 | 回聚焦，保留镜头 |
| 快读窄屏 | 约 75dvh 抽屉 | 模态，背景隔离 | 回聚焦 |
| 深读 | 纸正文＋目录＋出处 | 模态完整阅读 | 先回快读，再聚焦 |
| 专注修习 | 稳定工作台＋外围星图 | 学习、复习、测验任务 | 模块/上级任务 |
| 宽幅工作台 | 日期或起卦步骤 | 黄历、占筮 | 模块/结果 |

四阅读状态与其他工作台共用现存 panel，但不能因此共用错误的深读计数逻辑。
隐藏旧尺寸控件不应覆盖原用户布局偏好。
同一卦快读/深读必须复用内容 DOM，避免笔记和滚动被重新渲染清空。

### 6.2 暖纸阅读结构

左目录、中央正文、右出处在空间允许时并列。
窄屏目录和出处通过原生 details 按需展开。
正文内容顺序保持卦象与上下卦→处境→卦辞→彖象→六爻→关系→笔记与出处。
六爻正文初至上；图初爻在下。
sticky 阅读条不能遮挡章节标题，当前有 `scroll-margin-top`，仍需真实点击与滚动核验。
当前本轮 e2e 六爻页签失败必须先定位，不能仅因为属性同步测试通过就关闭任务。

### 6.3 控件隐藏与 Tab 顺序

视觉隐藏、鼠标不可点和键盘不可达是三个不同条件。
关闭区域应采用 `hidden`、`display:none`、适当 `visibility:hidden` 或 inert 等真正移出交互的方法。
仅 `opacity:0` 和 `pointer-events:none` 不会自动移出 Tab 顺序。
当前快读 `.relation-layers` 使用 opacity/pointer-events 隐藏，需实际核验常驻 select/按钮是否仍可 Tab 到。
该风险进入 `T-MODAL-01`，本轮没有假定已复现或已修复。
隐藏区重新显示后要恢复原 enabled 状态，不能为了移出 Tab 把业务控件永久 disabled。

## 7. 共享组件的全状态规格

### 7.1 按钮与链接

| 状态 | 视觉 | 语义/行为 |
| --- | --- | --- |
| 默认 | 主按钮局部铜金，次按钮银线，文字按钮克制 | 操作用 button，导航用 a |
| hover | 低幅表面变化，不大幅缩放 | 不触发业务和声音 |
| focus-visible | 明确轮廓，offset 不被裁 | 键盘可判断当前控件 |
| active | 约 1px 按下或轻微明暗 | 不以动画延迟操作 |
| disabled | 降亮、不可点 | 原生 disabled；旁边说明原因 |
| busy | 保留按钮宽度，文字说明进行中 | 防重复提交；必要 aria-busy |
| 成功 | 结果在内容区说明 | 不只变绿，不抢焦点 |
| 失败 | 说明原因和重试 | 不永久锁死按钮 |
| 切换选中 | 有下划线/边线和文字 | aria-pressed 或正确 tab 模式 |

不使用 `div onclick` 代替 button。
不嵌套 button/a 等交互元素。
没有可见文本的图标按钮必须有可访问名称。
下载和外链的名称应描述真实动作，不用“点这里”。

### 7.2 文本、数字和日期输入

必须有持久 label；placeholder 不能替代 label。
帮助文字通过 `aria-describedby` 关联。
无效值设置 `aria-invalid` 并连接字段错误。
提交失败保留用户输入，不把失败当成空表单重置。
原生 `min/max` 不足以防程序输入，业务层也要校验。
数字表单明确正整数、安全整数与支持范围，非法时不进入引擎。
文本域保存中、已保存、未保存和保存失败要能区分。
私人文本的默认保存边界必须与业务专题一致。
手机输入字号和布局应避免浏览器自动放大后无法操作。
只读字段和 disabled 字段有不同语义，不能为灰色外观随意互换。

### 7.3 select、单选和复选

图式 select 有明确名称和值，系统原生展开即可。
多选动爻不能用单选语义；单个关系激活不能在视觉上像可同时多选。
复选项整个 label 可点击，文字与控件间距足够。
选择值改变后才更新成功状态和可选声音，不在 pointerdown 时提前提交。
键盘 space、方向键与原生行为不被全局快捷键劫持。
禁用项说明原因，不能只置灰一个未知图标。

### 7.4 主导航和页签

六主导航保持固定顺序，激活状态与真实工作区一致。
学习四入口可以使用完整 tab 模式，也可以原生按钮导航，语义和键盘需匹配。
采用 tablist 时实现方向键、Home/End、roving tabindex、aria-controls/selected。
采用按钮组时保证 Tab 可达、pressed/current 状态准确，不添加伪 tab 角色。
阅读五项当前是章节定位按钮，`aria-current` 只能有一个。
用户滚动正文时同步当前章节，但不能每帧完整扫描或重复写历史。
键盘切换学习 tab 后焦点保留在 tab，不能被迟到的 rAF 强制拉进正文。
点击“进入课程”等明确操作时才按流程把焦点引入标题。

### 7.5 折叠区

优先原生 details/summary，或者真实 button+aria-expanded+aria-controls。
折叠后内部控件同步退出 Tab。
展开不强制把整页滚到顶部。
目录、出处、工具、六爻折叠分别保留自己的状态，不能用一个 open class 连带全部改变。
从宽屏变窄时同步默认呈现，但不能在每次快/深切换时重置用户刚展开的内容。
Escape 只关闭当前上层交互，不连续关闭两个层级。

### 7.6 搜索 combobox

输入框有名称、expanded、controls，并关联结果列表。
输入和方向键只改变建议/活动项，不计深读、不擅自变更当前星图焦点。
Enter 或点击结果才确认聚焦。
Escape 先关闭搜索建议，保留原有焦点卦和关系。
空结果显示关键词和可恢复建议，不用空白列表。
输入非法六位编码不报底层堆栈。
活动项通过 aria-activedescendant 或等价方式明确，ID 不重复。
搜索无须听到每次键入的音效，不加载远程文本服务。
主界面被手机模态隔离时搜索不应留在背景 Tab 顺序。

### 7.7 加载、错误、空态与反馈

| 类型 | 必需内容 | 不允许 |
| --- | --- | --- |
| 加载 | 正在做什么、保留布局、必要 aria-busy | 永久无文字 spinner |
| 模块加载失败 | 原因概要、重试、返回 | 抛出错误后空 panel |
| 空态 | 为什么为空、一个合适下一步 | 把空队列称为出错 |
| 存储失败 | 当前操作已完成但哪些记录未保存 | 假报保存成功 |
| 内容待校验 | 具体层次、来源状态和限制 | 视觉上隐藏成难读小字 |
| 测验反馈 | 本次结果、依据、记录变化、下一步 | 单次答对称已掌握 |
| 复习反馈 | 明确基于自评、下次时间和重看建议 | 自评按客观正误奖励 |
| 成就提示 | 名称、证据、延后展示 | 遮住经文或刚完成的答案 |

错误详情和内部堆栈不直接暴露给用户。
用户可复制必要诊断时，要先过滤私人文本和内部配置。
Live region 只播报状态摘要，整页刷新不能不断重读完整经文。

## 8. 图标与真实信息层

### 8.1 本地 Lucide

当前 `web/js/ui-icons.js` 使用本地静态路径生成 SVG，安装需幂等。
主要图标使用同一线宽、圆角和尺寸体系，颜色继承 currentColor。
许可证保留在 `web/lib/vendor/LUCIDE-LICENSE.txt`。
装饰图标 aria-hidden，意义由可见文字或按钮名称承担。
图标不是唯一名称，关闭、音效、日期导航和分享都要有文字语义。
不从 CDN 动态加载图标，不因为换图标引入框架。

### 8.2 残留整理

当前主外壳和多个关闭图标已替换，但黄历前后日、术语关闭等仍有字符箭头/×。
测验等反馈也有 ✓/✗ 字符，应逐处判断它是内容文本还是冒充图标。
`T-ICON-01` 负责完整清单、替换和灰度/强制颜色验证。
不使用 emoji 作为主系统图标，不依赖某台电脑恰好能显示特殊字形。
传统卦符、天干地支和真实文字符号是内容，不应被图标清理误删。

### 8.3 无字资产

背景图只提供星云、纸纤维和无字铜器材质。
刻度、方位、卦名和印章名称由实时数据绘制。
`taiji-mechanism.webp` 在基线已有细环伪文字风险，当前课程仍引用该图。
现有 CSS 主要是圆角和滤镜，不能据此认为刻痕已遮蔽。
`T-ASSET-02` 需实际复核、替换无字版本或完全遮蔽刻度后重绘。
替换后检查许可、尺寸、加载体积和对应截图。

## 9. 星图文字与关系识别

### 9.1 标签优先级和避让

已确认优先级：当前卦→关系卦→搜索/任务目标→八卦地标→普通标签。
卦名与关键词共享屏幕空间布局，间距至少 7px。
重要标签先尝试换位置，次要关键词无位置则隐藏。
当前卦最多三条关键词，关系目标各最多一条。
文字不得压星核、焦点光圈、导航、工具、摘要或缩放控制。
镜头运动时使用稳定排序与缓存，避免标签反复闪现。
缩放后逐级显现，不在全景常驻全部六十四个卦名。
当前共享布局和测量缓存已经实现，仍需继续用长词、边缘和真缩放验收。

### 9.2 关系的非色彩语义

| 关系 | 已确认视觉方向 | 必须解释 |
| --- | --- | --- |
| 综 | 金色实线、双向箭头 | 六爻上下倒转 |
| 错 | 朱砂长虚线 | 阴阳全部互换 |
| 互 | 青玉点线 | 2-3-4 与 3-4-5 取卦 |
| 变 | 铜白流动或稳定线型替代 | 明确哪些动爻改变 |

每次只激活一种关系，不能把全部连线铺满。
减少动态时保留变卦含义与方向，不能靠流光才看懂。
图例和文字列表提供等价说明，关系种类不只靠颜色。
`T-STAR-02` 需要核对当前实现与此目标、关系对读和探索路径，不重复改已正确的纯算法。

## 10. 指针、触摸和手势

鼠标点选与触摸选择均在确认动作后进入聚焦。
触摸抬起前不选卦；移动超过 6 CSS px 视为拖动。
阈值使用 CSS px，不能直接用 backing-store 像素。
拖动旋转星图时不误开快读或深读。
二次选择和拖动能中断选卦镜头与首次展开。
点击控制区不应穿透到 Canvas 选星。
横滚页签、日期轴和文字选择不得被全局手势拦截。
触摸取消、指针移出、窗口失焦和多指情况应复位拖动状态。
浏览器原生页面缩放不应被无条件禁止。
核心手势必须有键盘或 DOM 选择的等价途径。

## 11. 动效节奏与实现边界

### 11.1 时间表

| 动作 | 已确认节奏 | 约束 |
| --- | --- | --- |
| 首次进入星图 | 约 900ms，每会话一次 | 输入立即可用、可中断 |
| 选卦镜头 | 约 450ms | 再选或拖动从当前状态接管 |
| 普通界面 | 180—240ms | 不因层层 stagger 延迟可读性 |
| 成就铜印 | 约 1.2s | 结果展示完成后、不遮挡 |
| 日期变化 | 数字/轴按方向轻移，其他交叉淡入 | 不重放整屏入场 |
| 动爻 | 一次变化 | 不循环、不自动跳下一爻 |

普通 hover 和按下反馈只需小幅颜色/位移。
不为所有按钮加磁吸、光圈、鼠标拖尾或旋转。
当前主题已隐藏 pointer aura/cursor trail，不能因旧模块仍有代码而重新启用。
表单错误、测验结果和经文优先稳定呈现。
动画期间 opacity 不能长期停在半透明导致纸正文灰暗。
快/深切换复用正文时应取消旧 tween 并呈现稳定值。

### 11.2 可中断与清理

每个动画有明确拥有者和取消入口。
模式切换、关闭层、再次选卦、拖动和减少动态改变时取消无效演出。
过期回调不得重新打开已经关闭的面板或偷走焦点。
读取尺寸、写样式和绘制要安排有序，避免每次 pointermove 强制布局。
不能只在视觉上停止，却继续运行 D3/Three.js/RAF 的无用更新。
多个暂停原因按集合或等价机制独立保存。
关闭工具只能释放工具原因，不能释放仍有效的深读、后台或其他遮罩原因。

### 11.3 减少动态

同时处理 CSS、GSAP、Lenis、Canvas、Three.js、D3 和 Web Audio 相关自动演出。
仅把 CSS duration 改成 0.01ms 不足以证明场景稳定。
减少动态时直接显示最终图式、当前卦和完整文本。
自动旋转关闭；物理布局停稳；焦点脉冲和时间材质不持续改变。
关系仍可逐步观察，但以直接切帧替代连续旋转。
背景与窗口缩放后允许一次必要重绘，不要求永远完全不绘制。
页面内切换偏好后及时响应，不要求重新加载才能停止。
离开减少动态时也不能绕过现有暂停原因偷偷恢复动画。

## 12. 声音方案：批准内容与当前差距

### 12.1 已批准试听结论

试听记录为 `docs/auditions/uisfx-2026-08-15/README.md`。
已确认正式方向是 **B 质感增强**，A 原声只作评审对照。
B 是音色处理方向，不意味着所有候选声音都获准。

| 状态 | 候选 |
| --- | --- |
| 保留 | `zen/volume-change`、`zen/open`、`zen/close`、`zen/expand`、`zen/collapse` |
| 待定 | `zen/select`、`zen/toggle-on`、`zen/toggle-off`、`mechanical/snap` |
| 弃用 | 九项 Zen 学习反馈：check、progress-step、checkpoint、success、info、error、warning、complete、achievement |
| 弃用 | `mechanical/lock`、`mechanical/unlock` |

学习奖励、纠错、完成、成就和核心机械锁定需要第二轮独立声景。
铜钱、纸张、毛笔、印章和转盘棘轮需要有来源的真实拟音。
不能因 B 方向已选，就把弃用的 complete/achievement/lock 恢复接入。
旧基线中早期“Zen 步进声”的表达应服从后续试听结论和显式业务触发要求。

### 12.2 当前实现风险

当前 `audio-engine.js` 使用 Web Audio 合成多种声音，并提供总开关。
`main.js` 仍调用 `bindInterfaceSounds(document)`。
该函数从 document click、class、dataset 和上下文推断 cue。
复习自评被映射到 correct/wrong/tap。
梅花起卦按钮被映射到 complete，金钱按钮映射 coin。
黄历区域点击会走 page cue，包含术语。
这些并不满足“业务成功后显式触发”和“自评/术语保持安静”的目标。
不能把当前合成声写成已完成正式 B 素材接入。
任务 `T-SOUND-01` 处理语义触发，`T-SOUND-02` 处理素材、音量、冷却与疲劳验收。

### 12.3 语义触发规则

| 操作 | 允许触发的时机/行为 |
| --- | --- |
| 开/关/展开/收起 | 确实成功改变状态后，且使用已批准 cue |
| 复习三档自评 | 新学习声景批准前保持安静 |
| 金钱起卦 | 与真实六掷/结果状态一致，不从任意按钮名猜完成 |
| 梅花起卦 | 输入有效、结果生成并落定后才允许完成反馈 |
| 保存笔记/数据 | 保存成功才反馈，失败不能播成功声 |
| 测验 | 判分和记录结果明确后，使用后续批准的声音 |
| 成就 | 首次真正解锁且结果已展示后，不能重复播 |
| 术语、宜忌点击 | 保持安静 |
| 悬停、打字、持续缩放、滚动 | 不播放 |
| 网络/存储失败 | 文字解释为主，不用刺耳惩罚声 |

不得从样式类名推断业务成功。
业务模块可调用统一声音接口，但不能各自创建不受控制的 AudioContext。
声音失败不能阻塞主任务。

### 12.4 正式声音交付要求

第一次主动用户交互后才解锁音频。
总静音可达、名称正确，并保留现有本地偏好。
总音量控制需明确范围、当前值、静音与恢复行为。
统一并发上限和冷却，快速重复点击不叠出高音量。
关闭层或中断机械动作时停止对应持续声，不切掉别的合法短提示。
后台不持续播放装饰音。
素材记录来源、许可、用途、处理参数、时长、峰值与响度。
正式音频使用本地资源和许可清单，不从 CDN 或 node_modules 运行时加载。
长时间使用和耳机环境单独试听，不能用音量更大冒充质量更好。
这些项目尚未全部实现，不得只凭总静音按钮存在就填完成。

## 13. 模态、ARIA、焦点与背景隔离

### 13.1 共享模态约定

所有模态都有：可理解标题、正确 role/aria-modal、初始焦点、Tab 环、Escape、关闭入口、背景隔离和关闭后恢复。
只设 `aria-modal=true` 不会真正隔离背景。
只捕获 Tab 不会阻止读屏或指针访问背景。
打开前保存焦点和各背景节点原有 inert 值，关闭后逐个恢复。
不能一律设所有节点 inert=false，破坏别的上层状态。
嵌套预览或关系演示需明确栈顺序，Escape 只关闭最上层。
栈中底层关闭时，不得把焦点放回仍被顶层隔离的按钮。
触发元素被重绘移除时，使用当前上下文的备用标题/操作，而不是 body。

### 13.2 各层语义矩阵

| 层 | 模态规则 | 初始焦点 | 关闭恢复 |
| --- | --- | --- | --- |
| 欢迎 | 模态，背景 inert | 主开始路径 | 对应目的地或探索入口 |
| 搜索建议 | 非模态 combobox/listbox | 输入框保留 | 输入框/原焦点 |
| 桌面工具展开 | 普通非模态折叠 | 保留展开按钮 | 展开按钮 |
| 手机工具 | 模态底部工具面板 | 面板内合适首项 | 工具展开按钮 |
| 桌面快读 | 非模态 | 标题/当前操作 | 当前卦研读入口或 Canvas |
| 手机快读 | 模态 | 标题/当前操作 | 当前卦研读入口 |
| 深读 | 模态 | 标题或层级切换动作 | 快读相应操作 |
| 分享图片预览 | 模态，可能位于阅读上方 | 关闭/主保存动作 | 分享按钮 |
| 关系演示 | 模态 | 关闭或演示标题 | 关系演示按钮 |
| 卦序转盘 | 模态工具 | 关闭/明确转盘控制 | 探索工具入口 |
| 演变实验室 | 独立工具层，受门禁 | 标题/首个编辑控件 | 原入口或阅读上下文 |
| 黄历术语当前弹窗 | 当前是模态；目标改内联 | 当前关闭按钮 | 当前术语 |

此表规定验收，不声称所有层已经统一使用同一个工具函数。
现有分散实现应按 `T-MODAL-01` 逐步统一语义和栈管理，不引入新运行时。
黄历目标内联术语应由 `T-CAL-02` 替换其弹窗，而非再封装一遍旧行为。

### 13.3 读屏内容结构

每个主要工作区有可导航标题和明确区域名称。
正文以正确 h 层级、段落、列表和引用呈现，不能全部 div+大字。
图形卦象提供卦名/上下卦等可理解描述。
装饰 Canvas 不应重复朗读全部内容；交互 Canvas 有操作说明和 DOM 等价列表。
当前关系、动爻、缩放和焦点状态用必要摘要表达。
不能把全部 64 卦长经文作为 Canvas 的 aria-label。
结果更新后用礼貌 status，不无条件使用 interruptive alert。
输入校验错误要与字段关联，提交后必要时聚焦第一个错误。

## 14. 键盘路径逐项验收

### 14.1 欢迎与导航

1. 首次进入只能 Tab 到欢迎层可操作内容。
2. 三条开始路径可用 Enter/Space 进入明确场景。
3. 深链进入不会先被欢迎层遮住。
4. 六导航全部可达，激活状态可识别。
5. 模块异步加载时不丢焦点，失败重试可用。

### 14.2 探索与阅读

1. 聚焦搜索，输入名称，方向键和 Enter 确认。
2. 搜索建议 Escape 关闭但不清当前卦。
3. 打开工具，切换图式、关系、动爻，再关闭。
4. 可访问文字列表选择卦，焦点/摘要同步。
5. Enter 进入快读，五个章节按钮逐项定位。
6. 输入未保存笔记，切深读、快读，再回原卦检查草稿。
7. Escape 按深读→快读→聚焦→全景逐层返回。
8. 浏览器前进后退恢复状态，不重复计数。
9. 桌面快读非模态时，Tab 不进入 visually hidden 控件。
10. 从宽屏缩到窄屏，工具和阅读不会互相残留 inert。

### 14.3 学习、复习和测验

学习四入口可切换，不被下一帧的旧焦点任务抢回正文。
课程目录、开始小试、单选答案、提交、反馈和下一步均可完成。
复讲文本域和本地自评在网络不可用时仍可操作。
复习卡未揭示时答案不被读屏提前读出。
揭示后自评可达，提交后明确下一次温故。
测验结果焦点与滚动确保下一题可见，不能只靠无条件 scrollIntoView 假定成功。
备份导入错误可以关闭或修正，不覆盖原数据。

### 14.4 黄历和占筮

日期、前后日、返回今日、术语和分享全部可完成。
金钱六掷过程有明确进度和结果，而非只有动画。
梅花非法输入有字段错误，修正后可重新提交。
解卦练习、评分依据和主动保存控制不能只靠鼠标。
结果进入经文再返回时，保留学习上下文。

## 15. 对比度、强制颜色与缩放

### 15.1 对比度

以 WCAG AA 常用要求作为验收基准：一般正文至少 4.5:1，大字至少 3:1。
控件边界、焦点和必要图形信息至少 3:1。
逐项测量真实合成背景，包括星云亮部、半透明工具、纸纤维和 hover 状态。
不能只计算 solid token 就判定半透明页面全部合格。
错误文字、来源待校验、禁用解释、placeholder 和次级按钮都要覆盖。
disabled 视觉可弱，但必须有明确状态且不能隐藏关键原因。
灰度检查关系类型、宜忌和题目正误仍能辨别。
当前没有本轮全站逐点对比度合格证据，继续标为待验收。

### 15.2 强制颜色

在支持环境启用系统 forced-colors。
检查按钮、input、select、checkbox/radio、焦点、tab 当前项、来源提示和图标。
不能用 background-only 实现选中或边框。
必要时采用系统颜色并保留边框，避免全局 `forced-color-adjust:none`。
Canvas 的必要信息必须能由 DOM 等价内容获得。
装饰背景可消失，核心任务不能因此失去入口。
当前完整强制颜色流程尚未取得证据。

### 15.3 真实 200% 缩放

使用真实浏览器菜单或可验证的原生缩放机制。
记录浏览器、缩放值、外窗和 CSS 视口，确认实际生效。
不要用设备 DPR、CSS transform、截图放大或 640px 视口替代。
原来的 IAB/独立 Chromium 缩放尝试未生效，历史记录已经明确未验证。
在 200% 下完成六导航、搜索、快/深读、课程、小试、复习、黄历和占筮。
双向内容以外不出现整页横滚；操作不被固定层永久遮挡。
如果只取得等效回流证据，报告只写等效回流。

## 16. 性能、降级与可用性

WebGL backing-store 总像素预算约 500 万，DPR 建议不超过 2。
预算以实际画布 width×height 计算，不以 CSS 尺寸猜测。
银河和纹理初始化/尺寸变化时预渲染，连续帧复用。
文字测量与标签布局缓存，避免每帧完整重算碰撞。
后台、深读和模态层暂停无用动画，多原因独立管理。
WebGL 创建失败或 context lost 时，Canvas 星图和全部阅读继续可用。
模块按需加载，资料大文件不加进首屏预缓存。
没有网络时可用已缓存核心内容，缺资料显示明确状态。
不因性能优化裁掉来源提示、键盘列表或错误恢复。
当前实现有相关预算和回归，但新 UI 在真机/长期会话的帧耗、内存和耗电仍需测量。
任务归 `T-PERF-01`，先记录再优化，不凭感觉继续调星数与分辨率。

## 17. 质量门槛与证据交付

### 17.1 逻辑和契约

- 标签跨类型、长词、边缘、稳定优先级、至少 7px。
- 聚焦/快读不计深读，深读幂等。
- 历史恢复不写新历史。
- 镜头、关系、轨迹和 resize 坐标恢复。
- 未保存笔记、章节和实际非零滚动保留。
- 手机模态/桌面非模态及断点切换。
- 多个暂停原因、WebGL 失败和减少动态稳定。
- 来源标签、六爻顺序、图形自下而上。
- 新逻辑模块有真实边界测试；coverage 的 include 范围明确。

### 17.2 真实交互

鼠标、触摸、键盘分别完成选卦、工具、动爻、快读、深读和逐层返回。
不能只在脚本 evaluate 中调用 `.click()` 完成新流程验收。
点击前记录真实坐标和遮挡，失败时保留截图、状态和控制台信息。
默认无截图和采集截图的测试都应稳定，不能依赖截图暗中增加 settle 时间。
当前两次失败必须先复现、采证和定位，修复后再完整复跑。
任何 rerun 通过都应保留此前失败和最终修复说明。

### 17.3 视觉与设备

覆盖五视口、渐/乾/坤三卦、多档缩放、四阅读状态和主要功能页。
对照历史图明确日期，不能标成同一代码快照的 before/after。
检查纸正文不被半透明 tween 灰化，sticky 不遮标题，手机没有双重滚动死区。
检查真实 200%、系统减少动态、强制颜色、Android Chrome、iOS Safari 和读屏。
未获得的项目继续标为未验证，不以“自动化全绿”替代。

### 17.4 必交材料

| 材料 | 最低内容 |
| --- | --- |
| 实现说明 | 需求 ID、变更行为、兼容影响、尚未实现 |

`npm run check` 是语法和基础格式/数据门禁，不是 ESLint 或类型检查。
项目没有 TypeScript，不能虚构“类型检查通过”。
`validate` 的覆盖率只代表配置核心模块，不能宣称所有 UI 渲染都有 99% 覆盖。
最终验收仍需 `npm run validate`、`npm run test:e2e` 和差异检查通过。
Windows 发行物需要独立构建和运行证据，远程发布是之后单独步骤。
