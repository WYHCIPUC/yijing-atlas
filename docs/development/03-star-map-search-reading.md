## 1. 状态口径、术语与不变量

### 1.1 需求、实现、验证三轴

| 轴 | 本专题的判定方式 |
| --- | --- |
| 需求 | “沉浸星仪”方案及 UI-DESIGN-BASELINE 中已确认的交互继续有效；本文对尚缺的细节给出执行默认。 |
| 实现 | 以当前代码可达路径为准；写了纯逻辑、存在 DOM 或有样式，均不自动等于用户流程完整。 |
| 验证 | 本轮 validate 通过 230 项；E2E 两次失败。失败点、命令和环境以验证专题为准，不引用旧交接中的通过结论覆盖本轮结果。 |

手机真实设备、屏幕阅读器、真实浏览器 200% 缩放均未验证。已有视口或触控模拟不能替代这些证据。

### 1.2 术语

| 术语 | 含义 |
| --- | --- |
| 六位码 | 六个 0/1 字符，自初爻到上爻；左侧第一位是初爻。乾为 111111，坤为 000000。 |
| 全景 | 当前没有聚焦卦，也没有阅读内容；可浏览图式和选择关系。 |
| 聚焦 | 已选定卦星与镜头目标，显示摘要；不是正式阅读。 |
| 快读 | 底部阅读抽屉；桌面约 46dvh，手机约 75dvh；不是正式深读。 |
| 深读 | 暖纸完整正文与目录、出处边注；属于正式阅读。 |
| 关系出现项 | 从某卦到某目标、指定一种关系及成立条件的 occurrence；不能仅用无向边代替。 |
| 视图快照 | 镜头、图式、关系、焦点、旋转和轨迹的值拷贝；不是学习数据备份。 |
| 来路上下文 | 打开阅读前所在课程、占筮结果、今日入口或关系路径，供明确返回。 |

### 1.3 不可改变的约束

- 保持原生 HTML、CSS、ES Modules、Canvas 与现有 Three.js；不引入 React、构建系统或新的组件运行时。
- 不改变六位码、错综互变规则、经典图式的传统方位或历法算法。
- 不把银河布局声称为真实天体坐标，或把项目环排声称为古代唯一固定图式。
- 同一页面维持一个 StarMap 实例；阅读层级变化不能销毁重建星图。
- 原典、易传、注疏、项目导读和现代参照必须区分；缺来源不可用 AI 自动补写冒充原文。
- 六家注疏发布门禁保持关闭，直到对应来源与双人校对要求真实满足。
- 悬停、聚焦、快读不得写正式深读成就或新增复习卡；深读沿用既有幂等规则。
- 私人笔记不进入公开分享图；本轮不增加云端同步。

## 3. 五图式与全景控制

### 3.1 当前事实

| 图式 | 可见内容 | 空间口径 |
| --- | --- | --- |
| 易象银河 project | 64 卦、八个下卦卦族、六爻卫星 | 项目解释性空间，自由旋转。 |
| 先天八卦 earlier-heaven | 八纯卦 | 乾南坤北、南上东左；不随拖动旋转。 |
| 文王卦序 king-wen | 64 卦 | 经典卦序，项目多环排布。 |
| 八宫卦序 eight-palaces | 八宫各八卦 | 本宫、一世至五世、游魂、归魂；角度是项目可视化。 |
| 十二消息 twelve-messages | 12 消息卦 | 常见月令配属，项目年轮。 |

图式选择会关闭当前阅读、清除阅读焦点并更新说明；关系工具区常驻图式、当前关系和状态。
展开区包含说明、图例、具体动爻及 DOM 可选卦列表；桌面是折叠区域，手机是底部模态工具面板。
经典图式关闭自动巡天，拖动只平移；银河支持两轴旋转。缩放实际范围为 30%—400%。

### 3.2 目标与执行默认

- 图式切换必须显示来源类别和适用范围，不以一个“传统图式”标签统称五种布局。
- 切换前尚有笔记草稿时保留运行内草稿；不能借图式切换写入或清空学习数据。
- 不新增“布局改变即正式学习完成”的副作用。
- 图式或关系参数非法时维持最近有效状态，并在 DOM 状态区说明未执行；不要绘制伪造布局。
- 固定方位的全景复位应恢复该图式的默认中心与比例，不借复位打开阅读。
- 工具区打开后焦点仍有明确关闭路径；隐藏时 hidden、inert 与可聚焦后代必须同步。

### 3.3 输入、返回与异常

- 鼠标：选择框切图式，按钮选关系；展开不遮住必要关闭控件。
- 触控：选择控件保持至少 44 CSS px 主要触点；工具面板可正常滚动，不能把滚动当星图拖动。
- 键盘：选择框与按钮使用原生语义；展开控件提供 aria-expanded/aria-controls；Escape 先关工具。
- 空态：没有聚焦卦时展示总览可选卦；变卦未选动爻时展示“请选择具体动爻”。
- 加载失败：核心卦象缺失进入全站数据错误，不把空星图显示为加载成功。
- 手机切换断点时先结束旧模态隔离，再建立新隔离，避免背景永久 inert。
- 页面刷新只按当前 URL 和既有布局偏好初始化；没有写入 URL 的临时关系与视角不承诺恢复。

### 3.4 验收

- Given 银河全景，When 切到先天，Then 只显示八纯卦且方向保持南上东左，自动巡天禁用。
- Given 八宫图式，When 查看任一宫，Then 八状态顺序与纯逻辑结果一致，来源不称为真实天球坐标。
- Given 手机工具展开，When 按 Escape 或关闭，Then 焦点回工具按钮，隐藏区不在 Tab 顺序中。
- Given 已有笔记草稿，When 切换图式再读回原卦，Then 本次运行内草稿仍在且正式笔记没有被自动覆盖。

## 4. 聚焦、统一退出与漫游路径：T-STAR-01

### 4.1 当前事实与差距

星图和搜索选择调用 focusHexagram，只聚焦并显示卦名、序号、上下卦、一句导读和研读按钮。
Canvas 的 pointerup 才确认选择，移动超过 6 CSS px 按拖动处理；pointercancel/lostpointercapture 不确认。
Canvas 双击空白当前直接 clearFocus，可能绕开 main.reading.focusedCode，导致摘要仍在。
详情关系跳转会追加轨迹，DOM 关系目标选择目前只聚焦，不追加同类路径。
轨迹底层最多五段；有清除和返回上一步，但缺可见文字面包屑。

### 4.2 目标规格

- 所有“退出聚焦”入口统一通过主流程清除 reading、Canvas 焦点、摘要、关系高亮和 URL 临时状态。
- 双击空白、摘要返回全景、Escape、轨迹清除不能各自维护不同状态。
- 点击关系目标时记录出发卦和目标卦；直接搜索新卦不伪造一条关系路径。
- 可见路径按最近五步呈现；执行默认将“步”解释为五个卦节点，而非五条边，超出从最旧节点裁切。
- 保留底层已有五段轨迹兼容性；调整可见路径时不能破坏旧快照恢复。
- 回退只回到最近关系来源；没有来源时维持当前焦点并告知无可返回轨迹。
- 同一卦重复选中不追加自环；同一点击事件不能追加两段轨迹。
- 返回全景保留用户当前关系类型与具体动爻，直到用户明确换关系或图式；不新增持久化键。

### 4.3 交互与验收

- Given 已聚焦渐，When 双击空白，Then Canvas 无 activeCode、摘要隐藏、reading.focusedCode 为空。
- Given 指针按在卦星上，When 移动 7 CSS px 再抬起，Then 只转动/平移，不聚焦新卦。
- Given 指针移动 6 CSS px 或更少且未取消，When 抬起，Then 最多确认一次选择。
- Given 关系路径乾→夬→大有，When 返回上一步，Then 回夬并保留本次关系与镜头规则。
- Given 由搜索选择新卦，When 查看路径，Then 不把搜索跳转冒充错综互变。
- Given 快读打开，When 在桌面操作星图，Then 当前阅读与新的聚焦变化有明确单一归属，不出现摘要与正文卦名冲突。

<a id="star-relation-style"></a>
## 5. 关系语义、颜色与线型：T-STAR-02

当前 Canvas 线色与基线不一致：错卦偏金短虚线、综卦偏紫虚线、互卦浅蓝点线、变卦暖金虚线。
执行时按以下已确认语义统一 Canvas、图例、关系按钮和对读界面。

| 关系 | 必须并存的编码 | 成立条件 |
| --- | --- | --- |
| 综卦 | 金色实线、双向位置翻转标记 | 六爻整体倒序。 |
| 错卦 | 朱砂长虚线、阴阳全换文字 | 六爻逐位取反。 |
| 互卦 | 青玉点线、2-3-4/3-4-5取爻标记 | 有方向的结构抽取。 |
| 变卦 | 铜白变化标记；正常动效可有一次流光 | 必须指定具体动爻；减少动态效果使用静态标记。 |

- 每次只激活一种关系；同一目标兼有多种关系时，可附文字徽记，但不把所有关系线同时点亮。
- 错综自反、同卦目标和互卦重复目标保持真实规则，不为了视觉强行添加不同目标。
- 色弱或灰度下仍可根据文字、线型、方向和动爻识别；颜色不能是唯一信息。
- 没有动爻条件时，变卦不显示唯一目标或“必然去向”。
- Given 同一卦切换四关系，When 逐项读取图例与 DOM 状态，Then 线型、名称、目标及规则一致。
- Given 综卦为自身，When 激活综层，Then 明确自反，不绘制到任意另一卦的装饰线。
- Given 减少动态效果，When 选择变卦动爻，Then 一次呈现稳定结果且文字足以说明变化。

## 6. 标签和学习任务目标：T-STAR-03

### 6.1 当前事实

名称与关键词已经共享屏幕避让、文字测量缓存和稳定优先级；当前卦最多三关键词，关系目标各最多一条。
现有 _getSpaceLabels 主要接 active、hover、focusVisible、图式和关键词数据；没有完整的课程任务目标注入接口。
搜索仅在用户确认后聚焦，不在每次按方向键时改变镜头；这个行为必须保留。

### 6.2 目标与执行默认

- 给 StarMap 增加最小任务目标输入接口，接收经过六位码校验的目标数组和来源类别；不得直接读课程 localStorage。
- 执行默认目标项只包含 code、kind、label；kind 限 search、learning；不包含私人问题或自由笔记。
- 优先级为当前卦、关系目标、搜索目标、学习任务、八卦地标、普通标签；同级以稳定卦序打破并列。
- 标签矩形至少相隔 7 CSS px，名称和关键词必须跨类型检测；边缘、星核、焦点光圈和UI控件同时为保留区域。
- 高优先级先尝试多个位置；次级关键词无空间则隐藏，不截断成难以理解的零碎文字。
- 镜头移动时可复用短期缓存，但已发生明显碰撞或控件尺寸改变时必须失效；不能为“稳定”让标签压住按钮。
- 课程离开或任务取消时清目标；不得留下上一课程的任务高亮。
- 任务目标显示本身不记浏览、深读、成绩、成就或复习。

### 6.3 验收

- Given 渐、乾、坤长短关键词混合，When 在多档缩放和 320px 视口观察，Then 当前卦名称优先，关键词不会压星核或控件。
- Given 同一组任务数据重复布局，When 输入顺序无业务变化，Then 输出排序稳定，不随帧随机闪烁。
- Given 学习任务有两个目标，When 退出课程，Then 标签目标清除而学习记录不改变。
- Given 标签数量增加，When 连续绘制，Then 不在每帧完整测量全文与重算关系；用性能证据证明缓存有效。

## 7. 搜索规格：T-SEARCH-01

### 7.1 当前事实

首次建档时，主入口只支持卦名、全称、经传及爻辞文本包含检索；展示编号和六位码不等于支持按这两项搜索。
2026-10-25最新实施：T-SEARCH-01完成。结构查询、排序去重、真实八卦/共享关键词、语法帮助、IME/ARIA及异步保护已整合；手机六位码隐藏已修复，320/390/768可见及点选3/3，含仅关键词匹配的1440/390完整输入2/2。validate 62脚本、317/317与完整五视口E2E通过，仍最多八项、只聚焦。详见[搜索交接](evidence/2026-10-25-search-integration.md)及[专项报告](evidence/2026-10-25-search-input-probe.md)。真机、原生IME、读屏/真实200%继续保留外部验收边界。
方向键、Home/End、Enter、Escape、Ctrl/Cmd+K 和斜杠快捷键已经存在；取消搜索不改变原聚焦与关系。

### 7.2 输入规则与排序执行默认

- trim 查询；空串关闭建议，不列出全部 64 卦；保留输入法组合期间的正常文字输入。
- 精确六位 0/1 优先按编码匹配；全数字 1—64 优先按卦序匹配，支持“第N卦”的明确形式。
- 卦名/全称精确匹配优先于文本包含；再匹配上下卦，最后匹配关键词和经传正文。
- 上下卦明确格式支持“上乾下坤”“下坤上乾”；执行默认不猜测无方向的“乾坤”是否指某一复卦。
- 多字段命中同一卦去重；同级按文王卦序稳定排序；不在界面泄露整段经文作为巨大搜索结果。
- 非法编码、超范围卦序不抛全站错误；显示无结果或明确格式提示，不回退成任意卦。
- 查询时不写 URL、不写学习数据；确认结果只聚焦，研读另由用户触发。

### 7.3 所有状态与验收

- 正常：展示匹配编号、名称、全称和六位码，当前选项有 aria-selected 与 aria-activedescendant。
- 空/无结果：关闭或展示“没有找到相关卦象”；无结果时 Enter 不触发默认卦。
- 加载：搜索依赖核心索引；核心未完成前输入不可生成假结果。
- 错误：索引意外缺失要显示局部不可用；不能抛错使导航失效。
- 鼠标与触控：点结果确认一次；点击外侧关闭建议但不退出旧聚焦。
- 键盘：选项变化不移动镜头；Escape首先取消建议，第二次才按阅读层级返回。
- Given 输入 111111，When 确认，Then 聚焦乾但不新增复习卡。
- Given 输入 64 或第64卦，When 确认，Then 匹配未济且保持底到顶编码规则。
- Given 输入上乾下坤，When 查看结果，Then 匹配上下卦字段而不是名称包含猜测。
- Given 已聚焦渐并切换互层，When 搜索无结果后 Escape，Then 仍是渐与互层。

## 8. 快读、深读和阅读保存：T-READ-04、T-SAVE-01

### 8.1 当前事实

快读与深读共用 renderHexagramDetail 生成的长正文；桌面快读仍有星图操作区。
这已经完成层级拆分，但不等于基线提出的“左身份、中核心经文、右关系和学习状态”快读摘要布局。
首次建档时正式深读的成就与复习卡保存结果尚未统一反馈；T-SAVE-01已于2026-10-25完成分项状态、原轮幂等重试及真实输入验收，见[保存与考评交接](evidence/2026-10-25-contract-input-integration.md)。本节剩余建设属于T-READ-04的快读信息布局，不重复开发已交付的保存反馈。

### 8.2 目标规格

- 快读桌面采用身份、当前处境/经文摘要、关系/学习状态三个信息区；小屏合为单列，同一段正文不复制两份可编辑笔记。
- 概览、卦辞、彖象、六爻、关系是稳定章节入口；正文最大约 720px、18px/1.9，辅助文字不低于 15px。
- 快读默认 46dvh、手机约 75dvh；320px 和短屏允许内部滚动，主关闭、深入和当前章节可达。
- 深读展现目录、暖纸正文、来源边注；≤1100px目录/边注按需展开，不能隐藏校验状态本身。
- 同卦切换快深读不重建正文，不丢 textarea、章节和实际滚动；换卦前先记运行内草稿。
- 深读副作用分别尝试，区分已读证据保存与复习卡保存；失败显示内嵌状态并允许重试未成功部分。
- 执行默认重试复用原事件幂等键，不把重试作为第二次正式阅读；复习卡已有时不改变到期时间。
- 关闭阅读不自动保存私人笔记；刷新前草稿没有持久化承诺，应提供可见的“未保存”状态。
- 页面刷新可由 hex 深链恢复深读卦；没有明确存储的章节与滚动不声称已恢复。

### 8.3 验收

- Given 同一卦快读输入未保存笔记并滚到六爻，When 深入再回快读，Then 同一输入节点和内容、章节、实际滚动保留。
- Given 空间不足，When 手机进入快读，Then 背景不可Tab进入，关闭后焦点回研读按钮或有效Canvas入口。
- Given 复习卡写入失败但成就成功，When 进入深读，Then 提示哪项未保存，重试不重复增加成就。
- Given 卡已存在且未来到期，When 重开深读，Then 不重置该卡的 stage、reps、due。
- Given WebGL不可用，When 打开快读和深读，Then 经文、笔记、分享和关闭全部可操作。

## 9. 逐爻阅读：T-READ-01

当前六爻正文按初至上排列，但条目是普通 div；没有点击爻与卦图对应高亮的完整联动。

- 目标入口：六爻章节；前置为有效卦码与位置 1—6，不以数组索引冒充爻位。
- 执行默认选中初爻；切换卦时重置，快深读同卦切换保留位置。
- 每条爻提供原生按钮或完整键盘可达控件，显示爻名、阴阳与位置；不可只有颜色高亮。
- 选中只突出图中对应爻，并显示该爻爻辞、小象、项目解释、来源状态和边界；缺字段明确“暂无/待校验”。
- SVG始终初爻在下；正文导航始终初、二、三、四、五、上，不通过倒序正文迁就图象。
- 存在用户已指定动爻时，首次选中可播放一次变化；重选同项、滚动、章节切换不得循环播放。
- 鼠标/触控点击条目；键盘方向键在六爻内移动、Home/End到首末，Enter/Space确认；焦点与选中状态可区分。
- 选爻不新增正式阅读、复习卡或解卦成绩；它是阅读呈现状态。
- Given 坤卦，When 选择第二爻，Then 图中自下第二条高亮，正文展示六二，不误取数组反序位置。
- Given 缺项目解释，When 选中爻，Then 不填造内容，原文仍可读且待校验标记可见。
- Given 减少动态效果，When 选择动爻，Then 直接稳定呈现改变前后，不自动跳下一爻。

## 10. 关系对读与演变：T-READ-02

### 10.1 当前事实

详情同时列出错、综、互与六个单爻变候选；演示打开独立弹层，用户按“变化”逐帧观看。
关系演示打开即记录 relation.examined 幂等事件；不是播放完成才记录。
当前不提供对读目标的“在星图定位/研读目标”双动作，也没有统一单关系对读布局。
演变实验室已有任意爻切换、预设、撤销/重做/重置、播放/暂停、逐帧和速度选择。

### 10.2 目标规格

- 对读一次呈现一种关系，结构为本卦→明确变化规则→目标卦；每个关系保留来源与适用边界。
- “在星图定位”关闭阅读后聚焦目标，不记深读；“研读目标卦”保留当前阅读层级并选择关系章节。
- 互卦显示来源爻到目标爻的对应，而非假装所有爻逐位取反；综卦说明倒序位置。
- 变卦必须指定一条动爻；多爻实验属于演变实验室，不混用单爻候选的名称。
- 进入实验室时带入本卦与指定变化；退出恢复原阅读/镜头，结果打开时有明确来路。
- 播放中禁用互相冲突的编辑；关闭取消计时器，切模块不遗留后台播放。
- 撤销/重做只改变本次实验，不回滚笔记、成绩、成就或复习卡。
- 纯结构推演不依赖注疏发布；任何注疏/分家内容仍按内容门禁判定，入口显示不得绕过门禁。

### 10.3 验收

- Given 互卦对读，When 查看步骤，Then 显示2-3-4成下与3-4-5成上，目标与纯函数一致。
- Given 对读目标，When 选在星图定位，Then 只聚焦；When 选研读，Then 才按当前层级打开目标。
- Given 实验播放中，When 关闭并重开，Then 无旧计时器继续改变新会话。
- Given 连续打开同一关系，When 查看成就事件，Then 幂等键不造成重复证据。
- Given 注疏未发布，When 使用结构实验，Then 不显示任何未校注疏正文。

## 11. 上下文、URL与退出：T-READ-03

当前深链与关系章节恢复已存在，但课程/起卦结果的完整返回上下文未接通。
执行默认新增仅运行内的阅读来路对象，包含 kind、可序列化标识、可恢复状态和有效返回控件引用；不放 DOM 到 history.state。
kind 限 explore、daily、course、divination、relation、share；没有合法来路时回站内探索。

- `?hex=六位码`继续表示深读；分享与外部旧链接不能改成仅聚焦。
- 课程经文入口带课程id、目标卦和章节；返回课程恢复该课及滚动，不退到学习首页。
- 占筮入口保留本次cast及结果区域；返回不重新随机起卦、不再写历史。
- 关系入口默认关系章节；今日一卦默认概览；分享深链默认概览。
- 浏览器前进后退只恢复历史，不 push 新条目；章节跳转可replace，普通滚动不逐帧写history。
- 直接外部深链没有站内前一页时，关闭回探索，不调用 history.back 离开本站。
- 来路信息过期或刷新丢失时显示正常站内阅读；不猜测课程或伪造起卦结果。
- Given 课程某卦六爻入口，When 深读再返回，Then 回同课程同位置，不重复记课程浏览或重新考评。
- Given 占筮结果，When 读本卦后返回，Then 原六爻与解释相同，历史记录数不增加。
- Given 外部直接hex链接，When 关闭，Then URL删除hex并留在站内。
- Given 前进后退三次，When 检查history长度和成就，Then 不持续增长或重复计正式阅读。

## 12. 卦序转盘

入口属于探索工具，不是第七主导航。前置为完整64卦，按文王序排序；缺失应局部提示不可用。
当前一次旋转约3.4秒，期间禁用再次启动；正常减速后落定，减少动态效果直接呈现结果。
随机只作为学习入口；必须保留“不用于决策或预测”说明。

- 正常结果显示序号、卦名、全称、公开导读和研读按钮，可再转。
- 旋转中显示状态；关闭取消动画和机械音，释放独立 guaxu 暂停原因。
- 键盘可启动、关闭、研读与再转；Escape只关闭最上层，不同时退出底层聚焦。
- 关闭恢复发起控件；从结果研读后进入明确深读，不让背景转盘继续运行。
- 不因抽到某卦就计正式阅读或新增卡；确认研读后才按深读规则执行。
- Given 连续快速按启动，When 第一轮尚未落定，Then 只运行一轮且不叠机械声。
- Given 转盘运行中关闭，When 再打开，Then 无旧结果回调覆盖新会话。
- Given 减少动态效果，When 启动，Then 有结果和可访问状态，不等待不可见动画。

## 13. 公开分享图片

当前流程为本地Canvas生成PNG→预览→系统文件分享或下载；不能称已发送到任何社交平台。
公开内容模型取卦序、卦名、全称、卦象、卦辞、项目导读等，不取个人笔记和起卦问题。

- 入口在阅读身份区；生成中禁用同按钮，失败后恢复并给局部错误。
- 预览包含有意义alt、发送和下载动作；系统不支持文件分享时隐藏发送、保留下载。
- 用户取消系统分享显示已取消，不记为发布成功；下载失败可以重试。
- 执行默认公开链接仅保留有效hex与正式支持的公开参数，不能把未来私人query原样复制到分享文案。
- 分享图公开经文仍有内容来源与文化学习边界；不把项目导读标成原典。
- 弹层关闭恢复阅读焦点；暂停原因share和reading独立，关分享不能恢复仍应暂停的深读动画。
- Given 已输入私人笔记，When 生成图和文案，Then 图片、URL和发送text均无笔记内容。
- Given navigator.share不支持，When 下载，Then 取得PNG且不要求登录或外部接口。
- Given 用户取消系统分享，When 回预览，Then 可再次下载且未记录“发布成功”。

## 14. 模态统一与性能降级：T-MODAL-01

- 已有主阅读和手机工具的背景隔离；关系、实验室、转盘、分享仍需统一嵌套模态策略。
- 执行默认维护最上层模态栈：仅顶层响应Escape、循环Tab；关闭顶层恢复下面一层的有效焦点。
- aria-modal不替代inert；隐藏弹层不能留下可Tab按钮或被读屏继续浏览的内容。
- 文本/Canvas逻辑与Three.js外框分离，WebGL失败只降级装饰，不阻断搜索、阅读、关系或笔记。
- WebGL backing-store总量约不超过500万像素；文字测量、银河纹理、标签布局复用缓存。
- 后台、欢迎、工具、转盘、分享、阅读和模块切换各自暂停；解除一个原因不能抹掉其他原因。
- Given 深读上再开关系弹层，When Escape一次，Then 只关关系；第二次才按深读→快读返回。
- Given WebGL初始化失败，When 从搜索完成读卦，Then Canvas及全部阅读功能仍可用且无持续异常重试。
- Given 页面隐藏再恢复，When 深读仍打开，Then 不因visibility恢复而启动不必要动画。
