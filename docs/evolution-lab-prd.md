# 演变实验室产品需求文档

## 1. 背景与目标

现有演变实验室位于卦象详情弹窗中，能演示逐爻、错卦、综卦和互卦变化，但语义反馈仅有爻位和原卦爻辞。新版本将其升级为“探索”模块下的独立桌面功能：动画每推进一帧，当前卦义、经传原文、项目释义和历代注疏同步更新，帮助用户同时理解“象如何变”与“义如何转”。

首版仅在六家注疏全量完成并校对后开放，不以未完成或示例内容公开上线。

## 2. 用户与成功标准

目标用户为希望系统学习卦象关系、经传层次和易学史差异的桌面端学习者。

成功标准：

- 用户从“探索 → 演变实验室”或卦象详情快捷入口进入，三步内开始推演。
- 每个动画帧在同一次界面更新中展示当前卦、变动爻及对应解释。
- 六十四卦、三百八十四爻的六家可适用注疏均有来源、卷次/章节和校对状态。
- 任一未校对、缺少定位或来源不可公开的条目都会阻止正式入口启用。

## 3. 信息架构与核心流程

“探索”保留星图主视图，并新增二级功能条：`星图探索 | 演变实验室`。详情中的“进入演变实验室”继续作为带当前卦参数的快捷入口。

独立实验室采用三栏桌面布局：左栏选择原卦与关系预设，中栏展示原卦、当前卦、六爻编辑和播放控制，右栏同步展示“当前卦义—本步爻义—历代注疏—典籍依据”。右栏可切换经传、六家和对读视图，但动画过程中不自动滚动，避免阅读位置跳动。

核心流程：选择原卦 → 切换爻或选择错/综/互 → 播放逐帧变化 → 阅读同步语义 → 查看来源影印定位 → 打开结果卦详情。

## 4. 功能需求

### 4.1 演变与同步语义

- 保留逐爻编辑、错/综/互预设、播放/暂停、上一步/下一步、速度、撤销、重做和重置。
- 每帧展示当前卦名、卦码、上下卦、卦辞、彖传、大象及项目自撰释义。
- 本步爻义并列展示变化前后所属卦的爻辞、小象与项目释义，清楚标记“结构对读”，不宣称存在唯一因果解释。
- 多爻演示的中间卦只用于结构学习；界面明确说明其不等同于传统占筮断法。
- `prefers-reduced-motion` 下直接切帧，语义内容仍完整更新。

### 4.2 六家注疏

首版验收边界固定为：王弼《周易注》、孔颖达《周易正义》、李鼎祚《周易集解》、程颐《伊川易传》、朱熹《周易本义》、来知德《周易集注》。按原书实际覆盖映射到卦、卦辞、爻、彖、象等锚点；原书没有对应条目时标记“原书无独立注文”，不得补写成原文。

注疏按时代排列，并提供单家阅读与并列对读。古籍原文、项目释义和编辑说明必须有明显视觉标签，不混排为同一来源。

### 4.3 典籍依据与校对

每条原文记录作者、书名、朝代、底本、卷次/章节、数字底本 URL、影印页定位、录入方式和两次校对记录。数字资源可从中国哲学书电子化计划的《周易正义》《周易集解》《伊川易传》《周易本义》《周易集注》建立索引；OCR 文本只能作为录入辅助，最终必须与影印页复核。

现代整理本只可用于校勘记录；未经许可不得复制其标点、译注或长篇文字。项目释义须为自撰，并标记“项目释义”。

## 5. 数据与技术约束

新增 `web/data/commentaries/`：

- `sources.json`：六家书目、底本、许可与数字来源。
- `manifest.json`：覆盖率、校对状态、内容版本和发布开关。
- `hexagrams/{binaryCode}.json`：按卦拆分的经传锚点与注疏，进入实验室后按需加载。

每条内容至少包含 `sourceId`、`anchor`、`text`、`volume`、`locator`、`sourceUrl`、`verificationStatus` 和 `reviewers`。构建仍保持零依赖；Node 校验脚本检查卦码、锚点、来源引用、重复条目、空文本和发布门禁。内容文件不得进入首屏预缓存。

## 6. 非目标

本期不做手机版专用布局、AI 自动解经、个性化断卦、现代版权注本全文和服务端账号同步。后续新增注家不改变首版六家完整性的定义。

## 7. 验收与发布门禁

- 独立入口、详情快捷入口、URL 状态、键盘操作和浏览器前进/后退正常。
- 动画、当前卦与语义面板在所有帧保持一致，无上一帧残留。
- 六家覆盖清单、缺项说明、来源定位和双人校对均通过内容校验。
- 单元测试覆盖帧到语义映射、缺失数据、非法锚点和发布开关；桌面 E2E 覆盖 1440px 与 1280px。
- `npm run validate`、`npm run test:e2e` 全部通过后，才可将 `manifest.releaseReady` 设为 `true`。

## 8. 风险

主要风险是 OCR 错字、异体字与版本差异、注疏锚点不一致、静态数据体积增长。通过影印复核、保留异文记录、按卦懒加载和不可绕过的发布校验控制风险。
