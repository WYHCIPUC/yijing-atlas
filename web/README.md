# 易经查阅网站

纯静态网站（原生 HTML + CSS + JavaScript），浏览器打开即可查阅《周易》六十四卦与八卦。零构建链、零依赖、离线可用。

## 本地运行

由于浏览器安全策略，直接双击 `index.html` 打开（`file://` 协议）时，`fetch` 无法加载 JSON 数据。需用本地 HTTP 服务器。

**固定端口 3030**（推荐）：

- **Windows**：双击 `serve.bat`
- **任意系统**：在 `web/` 目录运行 `bash serve.sh`

然后浏览器打开 **http://localhost:3030/**

或手动指定端口：

```bash
cd web
python -m http.server 3030
```

## 功能

### 第 1 期 · 查阅库
- **64 卦总览**：网格展示，每卦含 SVG 卦象（阳爻一长横、阴爻两短横）
- **卦象详情**：卦辞、彖传、大象、6 爻爻辞与小象、用九/用六、序卦传
- **全文检索**：按卦名/卦辞/爻辞实时过滤
- **八卦基础**：先天八卦符号 + 自然/德性/方位/家人属性表

### 第 2 期 · 记忆复习 + 测验
- **艾宾浩斯复习卡片**：448 张卡（64 卦级 + 384 爻级），SM-2 简化版间隔算法
- **翻转卡片 + 自评**：忘了/模糊/记得三档，按遗忘曲线安排下次复习
- **进度面板**：今日待复习数、已学习、已掌握、掌握度进度条，进度存 localStorage
- **测验**：3 种题型（卦象→卦名、卦名→卦象、爻辞→卦名），即时判分 + 错题本

### 第 3 期 · 完整内容与学习路径
- **十翼（《易传》）**：系辞上下、文言、说卦、序卦、杂卦，分节浏览（彖/大象/小象已随各卦展示）
- **象数理论**：阴阳、八卦生成、先后天八卦、五行、河图洛书、纳甲、爻位、错综卦等 9 条
- **学习路径**：L1 入门 → L2 本经 → L3 十翼 → L4 象数，分级课程 + 进度跟踪（localStorage）

### 第 4 期 · 占筮实践
- **三种起卦法**：金钱卦（六掷铜钱）、大衍筮法（按古法概率分布）、梅花易数（时间起卦，确定性）
- **变爻解读**：按朱子《易学启蒙》变爻通则，0-6 变爻分别取辞断之
- **本卦/变卦展示**：SVG 卦象标注变爻，附卦辞与所占爻辞
- **占卦记录簿**：历史记录存 localStorage，可回看复现

### 黄历模块（v1.1 新增）
- **完整农历算法**：内置寿星万年历级天文算法（VSOP87 太阳黄经 + ELP2000 月亮黄经 + 定朔定气），节气精确到分钟，覆盖任意日期
- **黄历主页**：以今天为切入，全面解读——农历日期、年/月/日干支、生肖、纳音、节气、建除值位、二十八宿、彭祖百忌、每日宜忌
- **全面解读**：每个术语（建除/宿/百忌/节气/神煞）可点击查结构化释义，依据《协纪辨方书》
- **黄历知识页**：分类浏览 98 条术语（建除12/宿28/百忌22/节气24/神煞12）
- **复习整合**：黄历术语作为复习卡片源，与易经卡片可切换/合并复习

### 通用
- **启动自检**：加载时校验 64 卦完整性，数据错误立即报错
- **响应式**：移动端自适应布局

## 数据说明

- `data/hexagrams.json`：**全部 64 卦公版《周易》原文**（约 2 万字），每卦含卦辞、彖传、大象传、6 爻爻辞与小象传、序卦传说明；乾/坤另含用九/用六。
- 卦以 **6 位二进制串（自下而上，阳1阴0）** 为唯一主键，如乾=`111111`、坤=`000000`、泰=`111000`。
- 启动时自动校验：64 卦数量、binaryCode 唯一性、卦序连续性、爻象与 binaryCode 一致性。

## 技术架构

```
web/
├── index.html              # 入口
├── styles/main.css         # 古朴棕色系样式
├── data/
│   ├── hexagrams.json      # 64 卦数据
│   └── trigrams.json       # 八卦数据
└── js/
    ├── main.js             # 入口：路由、初始化、搜索
    ├── data-loader.js      # 加载 JSON + 启动自检
    ├── hexagram-utils.js   # 卦位运算（错综卦、爻题、当位）
    ├── svg-painter.js      # SVG 卦象绘制
    └── render.js           # 渲染层
```

三层分离：数据层（JSON）→ 逻辑层（纯 JS 模块）→ 视图层（HTML/CSS）。JS 用 ES Modules（`import/export`）。

## 部署到 GitHub Pages

将 `web/` 目录内容推送到 GitHub 仓库，开启 Pages 即可，无需任何构建步骤。
